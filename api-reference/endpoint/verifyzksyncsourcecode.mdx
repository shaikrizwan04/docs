---
title: "Verify Smart Contract Source Code on zkSync Era Networks"
sidebarTitle: "Verify zkSync"
description: "Submit a Solidity or EraVM smart contract source code for verification on zkSync Era. Requires the zksolc compiler version parameter."
---

Use this endpoint to verify a contract deployed on a zkSync-based network. Verification works similarly to standard Solidity verification, but requires an additional `zksolcVersion` parameter for EraVM contracts. After submission, use the returned GUID to poll [checkverifystatus](/api-reference/endpoint/checkverifystatus) for the result.

<Tip>
  Set `chainid=324` for zkSync Era mainnet when calling this endpoint. Check [supported chains](/supported-chains) for other zkSync-compatible networks.
</Tip>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID of the zkSync network. Use `324` for zkSync Era mainnet. See [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="verifysourcecode">
  Set to `verifysourcecode` for this endpoint.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Request Body

Send the following fields as `application/x-www-form-urlencoded`.

<ParamField body="contractaddress" type="string" required>
  The address where the contract is deployed.
</ParamField>

<ParamField body="sourceCode" type="string" required>
  The Solidity source code to verify.
</ParamField>

<ParamField body="codeformat" type="string">
  The source format. Use `solidity-single-file` or `solidity-standard-json-input`.
</ParamField>

<ParamField body="contractname" type="string" required>
  The contract name, including file path if applicable. Example: `contracts/Token.sol:Token`.
</ParamField>

<ParamField body="compilerversion" type="string" required>
  The Solidity compiler version used. Example: `v0.8.24+commit.e11b9ed9`.
</ParamField>

<ParamField body="zksolcVersion" type="string" required>
  The zksolc compiler version. Required for EraVM contracts, optional for EVM contracts. Use the `v` prefix, starting from `v1.3.0`. Example: `v1.3.13`.
</ParamField>

<ParamField body="optimizationUsed" type="string">
  Required when `codeformat` is `solidity-single-file`. Use `1` if optimization was enabled, `0` if not.
</ParamField>

<ParamField body="constructorArguments" type="string">
  ABI-encoded constructor arguments used at deployment.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request was accepted, `0` if it failed.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  A GUID string for the verification submission. Poll [checkverifystatus](/api-reference/endpoint/checkverifystatus) with this GUID to track the result.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl -X POST "https://api.etherscan.io/v2/api\
?chainid=324\
&module=contract\
&action=verifysourcecode\
&apikey=YOUR_API_KEY" \
-d "contractaddress=0xdAC17F958D2ee523a2206206994597C13D831ec7" \
-d "sourceCode=pragma solidity 0.8.24; contract MyToken { ... }" \
-d "codeformat=solidity-single-file" \
-d "contractname=MyToken" \
-d "compilerversion=v0.8.24%2Bcommit.e11b9ed9" \
-d "zksolcVersion=v1.3.13" \
-d "optimizationUsed=0"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "324",
  module: "contract",
  action: "verifysourcecode",
  apikey: "YOUR_API_KEY",
});

const body = new URLSearchParams({
  contractaddress: "0xdAC17F958D2ee523a2206206994597C13D831ec7",
  sourceCode: "pragma solidity 0.8.24; contract MyToken { ... }",
  codeformat: "solidity-single-file",
  contractname: "MyToken",
  compilerversion: "v0.8.24+commit.e11b9ed9",
  zksolcVersion: "v1.3.13",
  optimizationUsed: "0",
});

const response = await fetch(
  `https://api.etherscan.io/v2/api?${params}`,
  { method: "POST", body }
);
const data = await response.json();
console.log("Verification GUID:", data.result);
```

```python Python
import requests

params = {
    "chainid": "324",
    "module": "contract",
    "action": "verifysourcecode",
    "apikey": "YOUR_API_KEY",
}

payload = {
    "contractaddress": "0xdAC17F958D2ee523a2206206994597C13D831ec7",
    "sourceCode": "pragma solidity 0.8.24; contract MyToken { ... }",
    "codeformat": "solidity-single-file",
    "contractname": "MyToken",
    "compilerversion": "v0.8.24+commit.e11b9ed9",
    "zksolcVersion": "v1.3.13",
    "optimizationUsed": "0",
}

response = requests.post(
    "https://api.etherscan.io/v2/api",
    params=params,
    data=payload
)
print("Verification GUID:", response.json()["result"])
```
