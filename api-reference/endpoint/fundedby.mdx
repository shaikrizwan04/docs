---
title: "Get the Funding Source That First Funded an EOA Address"
sidebarTitle: "fundedby"
description: "Retrieve the address and transaction that first funded a specific EOA. Trace the origin of funds for compliance, analytics, and attribution workflows."
---

Use this endpoint to look up the first transaction that deposited funds into an externally owned account (EOA). The response includes the funding address, the transaction hash, the block number, and the amount transferred. This is particularly useful for tracing the origin of funds in compliance workflows, linking wallets to known entities, and investigating fund flows on-chain.

<Note>
  This is a **PRO endpoint**, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls per second** regardless of your API Pro tier.
</Warning>

<Warning>
  This endpoint only works for **EOA addresses** (externally owned accounts). Querying a contract address will not return results.
</Warning>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet, `137` for Polygon, or any chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="fundedby">
  Set to `fundedby` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The EOA address to look up, for example `0x4838B106FCe9647Bdf1E7877BF73cE8B0BAD5f97`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. See [common error messages](/common-error-messages) for error values.
</ResponseField>

<ResponseField name="result" type="object">
  An object containing details about the first funding transaction.

  <Expandable title="result">
    <ResponseField name="block" type="number">Block number in which the funding transaction was included.</ResponseField>
    <ResponseField name="timeStamp" type="string">Time of the funding transaction, as a UNIX timestamp in seconds.</ResponseField>
    <ResponseField name="fundingAddress" type="string">The address that first sent funds to the queried address.</ResponseField>
    <ResponseField name="fundingTxn" type="string">Transaction hash of the first funding transaction.</ResponseField>
    <ResponseField name="value" type="string">Amount transferred in the funding transaction, in wei. Divide by `10^18` to convert to ETH.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=fundedby\
&address=0x4838B106FCe9647Bdf1E7877BF73cE8B0BAD5f97\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "fundedby",
    "address": "0x4838B106FCe9647Bdf1E7877BF73cE8B0BAD5f97",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
