title: "Check Smart Contract Source Code Verification Status"
sidebarTitle: "Check Verify Status"
description: "Poll the result of a Solidity, Vyper, or Stylus source code verification submission using the GUID returned by the verify endpoint."
---

Use this endpoint to check whether a source code verification submission has succeeded or failed. Pass the GUID you received from [verifysourcecode](/api-reference/endpoint/verifysourcecode), [verifyvyper](/api-reference/endpoint/verifyvyper), or [verifystylus](/api-reference/endpoint/verifystylus). Poll this endpoint every few seconds until you receive a terminal result.

<Tip>
  Verification typically completes within 30–60 seconds. Poll every 5 seconds and stop when `result` is `Pass - Verified` or contains an error message that won't change on retry.
</Tip>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID you submitted the verification on. Example: `1` for Ethereum mainnet. See [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="checkverifystatus">
  Set to `checkverifystatus` for this endpoint.
</ParamField>

<ParamField query="guid" type="string" required>
  The GUID returned by your verification submission request. Example: `x3ryqcqr1zdknhfhkimqmizlcqpxncqc6nrvp3pgrcpfsqedqi`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  Status of the verification submission. Returns `Pass - Verified` on success, `Pending in queue` while processing, or an error message describing the failure.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=checkverifystatus\

&apikey=YOUR_API_KEY"
```

```python Python
import requests
import time

def poll_verification(guid, chain_id="1", api_key="YOUR_API_KEY"):
    params = {
        "chainid": chain_id,
        "module": "contract",
        "action": "checkverifystatus",
        "guid": guid,
        "apikey": api_key,
    }
    while True:
        response = requests.get("https://api.etherscan.io/v2/api", params=params)
        result = response.json()["result"]
        print(result)
        if result != "Pending in queue":
            break
        time.sleep(5)

poll_verification("x3ryqcqr1zdknhfhkimqmizlcqpxncqc6nrvp3pgrcpfsqedqi")
```
