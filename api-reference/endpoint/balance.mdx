---
title: "Get the Current Native Token Balance for an Address"
sidebarTitle: "balance"
description: "Retrieve the current native token balance held by a specific address on any supported EVM chain. Returns the result in wei as a string."
---

Use this endpoint to fetch the current native token balance (ETH, BNB, MATIC, etc.) for any address on a supported chain. The balance is returned in wei — the smallest unit of the chain's native token. To display it to users, divide by 10^18 or use the [Etherscan unit converter](https://etherscan.io/unitconverter). For historical balances at a specific block, see the [Historical Balance](/api-reference/endpoint/balancehistory) endpoint.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet, `137` for Polygon, `42161` for Arbitrum, or any other chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="balance">
  Set to `balance` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The address to query, for example `0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae`. To query multiple addresses in one call, use the [Multi-Address Balance](/api-reference/endpoint/balancemulti) endpoint.
</ParamField>

<ParamField query="tag" type="string" default="latest">
  The block parameter to use. Pass `latest` for the most recent block, `earliest` for the genesis block, or `pending` for the pending state. Also accepts a specific block number in hex format (e.g., `0x10d4f`) for any block within the last 128 blocks.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if an error occurred or no records were found.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. On error, contains a description such as `NOTOK`. See [common error messages](/common-error-messages).
</ResponseField>

<ResponseField name="result" type="string">
  The account balance in wei. Divide by `10^18` to convert to the native token's base unit (e.g., ETH). Use the [unit converter](https://etherscan.io/unitconverter) for other denominations.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=balance\
&address=0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae\
&tag=latest\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "balance",
    "address": "0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae",
    "tag": "latest",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```

