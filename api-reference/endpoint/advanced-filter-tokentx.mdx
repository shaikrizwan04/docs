---
title: "ERC-20 Token Transfers Advanced Directional Filter"
sidebarTitle: "Advanced tokentx"
description: "Filter ERC-20 token transfers by sender, recipient, and/or contract address using AND/OR logic, with block range and pagination support."
---

The Advanced Filter variant of the ERC-20 token transfers endpoint lets you combine `from`, `to`, and `contractaddress` filters with an explicit operator for directional filtering. Use `fromto_opr=or` to find all ERC-20 transfers involving a specific address in either direction, or `fromto_opr=and` to find transfers specifically between two addresses. You can also combine directional filters with a `contractaddress` to narrow results to a single token.

<Note>
  This is a **PRO endpoint**, available on the [Standard Plan](/rate-limits) and above. It is currently in **Beta** — behavior may change.
</Note>

<Tip>
  Explore and preview data interactively using the [Advanced Filter](https://etherscan.io/advanced-filter) page on Etherscan before integrating this endpoint.
</Tip>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet or any chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="tokentx">
  Set to `tokentx` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string">
  The ERC-20 token contract address to filter by. Provide `contractaddress`, `from`, or `to` — at least one is required.
</ParamField>

<ParamField query="from" type="string">
  Filter transfers by sender address. Provide `from`, `to`, or `contractaddress`.
</ParamField>

<ParamField query="to" type="string">
  Filter transfers by recipient address. Provide `from`, `to`, or `contractaddress`.
</ParamField>

<ParamField query="fromto_opr" type="string">
  Required when `from` or `to` is provided. Use `and` to require both addresses to match, or `or` to match transfers where either address matches.
</ParamField>

<ParamField query="startblock" type="integer" default="0">
  Starting block number to search from.
</ParamField>

<ParamField query="endblock" type="string" default="latest">
  Ending block number to search to. Use `latest` for the current block.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination.
</ParamField>

<ParamField query="offset" type="integer" default="10">
  Number of records per page.
</ParamField>

<ParamField query="sort" type="string" default="desc">
  Sort order. Use `asc` for oldest first, `desc` for latest first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. See [common error messages](/common-error-messages) for error values.
</ResponseField>

<ResponseField name="result" type="array">
  An array of ERC-20 token transfer objects matching the filter criteria.

  <Expandable title="result[]">
    <ResponseField name="blockNumber" type="string">Block number in which the transaction was included.</ResponseField>
    <ResponseField name="timeStamp" type="string">Time the block was mined, as a UNIX timestamp in seconds.</ResponseField>
    <ResponseField name="hash" type="string">The transaction hash.</ResponseField>
    <ResponseField name="nonce" type="string">Number of transactions sent from the sender before this one.</ResponseField>
    <ResponseField name="blockHash" type="string">Hash of the block containing the transaction.</ResponseField>
    <ResponseField name="from" type="string">Address that sent the tokens.</ResponseField>
    <ResponseField name="contractAddress" type="string">Contract address of the token being transferred.</ResponseField>
    <ResponseField name="to" type="string">Address that received the tokens.</ResponseField>
    <ResponseField name="value" type="string">Amount transferred in the token's smallest unit. Divide by `10^tokenDecimal` for the display value.</ResponseField>
    <ResponseField name="tokenName" type="string">Full name of the token.</ResponseField>
    <ResponseField name="tokenSymbol" type="string">Symbol of the token.</ResponseField>
    <ResponseField name="tokenDecimal" type="string">Number of decimal places the token uses.</ResponseField>
    <ResponseField name="transactionIndex" type="string">Index position of the transaction within the block.</ResponseField>
    <ResponseField name="gas" type="string">Maximum gas the sender allowed.</ResponseField>
    <ResponseField name="gasPrice" type="string">Price paid per unit of gas, in wei.</ResponseField>
    <ResponseField name="gasUsed" type="string">Units of gas actually consumed.</ResponseField>
    <ResponseField name="cumulativeGasUsed" type="string">Total gas used up to and including this transaction in the block.</ResponseField>
    <ResponseField name="input" type="string">Input data sent with the transaction.</ResponseField>
    <ResponseField name="methodId" type="string">First four bytes of input data identifying the called function.</ResponseField>
    <ResponseField name="functionName" type="string">Decoded function signature when the contract is verified.</ResponseField>
    <ResponseField name="confirmations" type="string">Number of blocks mined after the block containing this transaction.</ResponseField>
  </Expandable>
</ResponseField>

## Example

This example fetches all MKR token transfers sent to a specific address.

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=tokentx\
&contractaddress=0x9f8f72aa9304c8b593d555f12ef6589cc3a579a2\
&to=0x4e83362442b8d1bec281594cea3050c8eb01311c\
&fromto_opr=or\
&startblock=0\
&endblock=latest\
&page=1\
&offset=10\
&sort=desc\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "tokentx",
    "contractaddress": "0x9f8f72aa9304c8b593d555f12ef6589cc3a579a2",
    "to": "0x4e83362442b8d1bec281594cea3050c8eb01311c",
    "fromto_opr": "or",
    "startblock": 0,
    "endblock": "latest",
    "page": 1,
    "offset": 10,
    "sort": "desc",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
