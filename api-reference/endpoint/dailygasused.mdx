---
title: "Get Daily Total Gas Used on the Network"
sidebarTitle: "dailygasused"
description: "Returns the total gas consumed by all transactions on the network for each day in a date range. PRO endpoint — Standard plan and above."
---

Total daily gas used measures the aggregate computational work performed across all transactions in every block on a given day. Tracking this over time helps you understand network demand, spot spikes caused by popular applications, and forecast future capacity requirements. This endpoint returns one data point per day for the specified date range.

<Note>
  This is a **PRO endpoint**, available to the [Standard Plan](/rate-limits) and above. Upgrade your API key to access it.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="dailygasused">
  Set to `dailygasused`.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format, e.g. `2019-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format, e.g. `2019-02-28`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order. Use `asc` for oldest-first or `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily gas usage data points.

  <Expandable title="Result item fields">
    <ResponseField name="UTCDate" type="string">
      Date of the data point in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="unixTimeStamp" type="string">
      Start of the UTC date as a Unix timestamp in seconds.
    </ResponseField>
    <ResponseField name="gasUsed" type="string">
      Total gas used by all transactions on this day.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=dailygasused\
&startdate=2019-02-01\
&enddate=2019-02-28\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "dailygasused",
  startdate: "2019-02-01",
  enddate: "2019-02-28",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "dailygasused",
    "startdate": "2019-02-01",
    "enddate": "2019-02-28",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
