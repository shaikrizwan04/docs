---
title: "Get Historical Daily ETH Price in USD"
sidebarTitle: "ethdailyprice"
description: "Returns the daily closing price of ETH in US dollars for each day in a specified date range. PRO endpoint — Standard plan and above."
---

Historical ETH price data lets you value on-chain balances at specific points in time, perform P&L calculations for tax or accounting purposes, and build time-series analyses of market behavior. This endpoint returns one closing price per day denominated in US dollars.

<Note>
  This is a **PRO endpoint**, available to the [Standard Plan](/rate-limits) and above. Upgrade your API key to access it.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="ethdailyprice">
  Set to `ethdailyprice`.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format, e.g. `2019-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format, e.g. `2019-02-28`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order. Use `asc` for oldest-first or `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily ETH price data points.

  <Expandable title="Result item fields">
    <ResponseField name="UTCDate" type="string">
      Date of the price in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="unixTimeStamp" type="string">
      Start of the UTC date as a Unix timestamp in seconds.
    </ResponseField>
    <ResponseField name="value" type="string">
      Closing price of 1 ETH in US dollars on this day.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=ethdailyprice\
&startdate=2019-02-01\
&enddate=2019-02-28\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "ethdailyprice",
  startdate: "2019-02-01",
  enddate: "2019-02-28",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "ethdailyprice",
    "startdate": "2019-02-01",
    "enddate": "2019-02-28",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
