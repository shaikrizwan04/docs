description: "Returns Etherscan name tags, labels, and reputation scores for up to 100 addresses per call. Requires Pro Plus plan — throttled to 2 calls/second."
---

Etherscan maintains a curated database of address metadata — name tags, labels, official URLs, short descriptions, reputation scores, and other attributes. This endpoint lets you look up that metadata for any address programmatically. It's particularly useful for compliance tooling (reputation scoring), analytics dashboards (entity labeling), and dApp UIs that want to display human-readable names for counterparties. You can submit up to 100 comma-separated addresses per call.

<Note>
  This is a **PRO Plus endpoint**, available exclusively to the [Pro Plus tier](https://etherscan.io/apis). It is throttled to **2 calls per second** regardless of plan level.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="nametag">
  Set to `nametag`.
</ParamField>

<ParamField query="action" type="string" required default="getaddresstag">
  Set to `getaddresstag`.
</ParamField>

<ParamField query="address" type="string" required>
  A single address or comma-separated list of up to 100 addresses to query.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if records were returned, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of address metadata objects.

  <Expandable title="Address metadata fields">
    <ResponseField name="address" type="string">The address the metadata applies to.</ResponseField>
    <ResponseField name="nametag" type="string">Public name tag assigned to the address, e.g. `Coinbase 10`.</ResponseField>
    <ResponseField name="internal_nametag" type="string">Secondary name tag for the address, if available. May be empty.</ResponseField>
    <ResponseField name="url" type="string">Official URL associated with the address.</ResponseField>
    <ResponseField name="shortdescription" type="string">Short description of the address or entity.</ResponseField>
    <ResponseField name="notes_1" type="string">Additional note about the address.</ResponseField>
    <ResponseField name="notes_2" type="string">Additional note about the address.</ResponseField>
    <ResponseField name="labels" type="array">Human-readable labels applied to the address, e.g. `["Coinbase", "Exchange"]`.</ResponseField>
    <ResponseField name="labels_slug" type="array">Machine-readable slugs for the labels, e.g. `["coinbase", "exchange"]`.</ResponseField>
    <ResponseField name="reputation" type="number">Reputation score. `0` = neutral, positive = trusted, negative = flagged.</ResponseField>
    <ResponseField name="other_attributes" type="array">Additional structured attributes.</ResponseField>
    <ResponseField name="lastupdatedtimestamp" type="number">Unix timestamp when the metadata was last updated.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=nametag\
&action=getaddresstag\
&address=0xa9d1e08c7793af67e9d92fe308d5697fb81d3e43\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "nametag",
  action: "getaddresstag",
  address: "0xa9d1e08c7793af67e9d92fe308d5697fb81d3e43",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result[0].nametag);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "nametag",
    "action": "getaddresstag",
    "address": "0xa9d1e08c7793af67e9d92fe308d5697fb81d3e43",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"][0]["nametag"])
```
