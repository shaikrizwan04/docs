title: "Get Token Metadata and Project Info by Contract Address"
sidebarTitle: "Token Info"
description: "Retrieve project details, social media links, token type, supply, and USD price for any ERC-20, ERC-721, or ERC-1155 token contract."
---

Use this endpoint to fetch enriched token metadata submitted to Etherscan, including the project description, official website, social media links, token type, total supply, and current USD price. This is useful for building token explorers, portfolio dashboards, and enriched analytics views. Only tokens with verified or submitted project info return a full result.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="token">
  Set to `token` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="tokeninfo">
  Set to `tokeninfo` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The token contract address to retrieve information for. Example: `0x0e3a2a1f2146d86a604adc220b4967a898d7fe07`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array containing a single token info object.
  <Expandable title="result item fields">
    <ResponseField name="contractAddress" type="string">
      Contract address of the token.
    </ResponseField>
    <ResponseField name="tokenName" type="string">
      Full name of the token.
    </ResponseField>
    <ResponseField name="symbol" type="string">
      Token ticker symbol.
    </ResponseField>
    <ResponseField name="divisor" type="string">
      Number of decimal places the token uses.
    </ResponseField>
    <ResponseField name="tokenType" type="string">
      Token standard: `ERC20`, `ERC721`, or `ERC1155`.
    </ResponseField>
    <ResponseField name="totalSupply" type="string">
      Total supply in the token's smallest unit.
    </ResponseField>
    <ResponseField name="blueCheckmark" type="string">
      `true` if the token is verified by Etherscan, `false` otherwise.
    </ResponseField>
    <ResponseField name="description" type="string">
      Project description submitted to Etherscan.
    </ResponseField>
    <ResponseField name="website" type="string">
      Official project website URL.
    </ResponseField>
    <ResponseField name="email" type="string">
      Project contact email.
    </ResponseField>
    <ResponseField name="blog" type="string">
      Project blog URL.
    </ResponseField>
    <ResponseField name="reddit" type="string">
      Project Reddit URL.
    </ResponseField>
    <ResponseField name="facebook" type="string">
      Project Facebook URL.
    </ResponseField>
    <ResponseField name="twitter" type="string">
      Project X (Twitter) URL.
    </ResponseField>
    <ResponseField name="github" type="string">
      Project GitHub URL.
    </ResponseField>
    <ResponseField name="telegram" type="string">
      Project Telegram URL.
    </ResponseField>
    <ResponseField name="discord" type="string">
      Project Discord URL.
    </ResponseField>
    <ResponseField name="linkedin" type="string">
      Project LinkedIn URL.
    </ResponseField>
    <ResponseField name="whitepaper" type="string">
      Project whitepaper URL.
    </ResponseField>
    <ResponseField name="tokenPriceUSD" type="string">
      Latest token price in US dollars.
    </ResponseField>
    <ResponseField name="image" type="string">
      URL of the token's logo image.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=token\
&action=tokeninfo\
&contractaddress=0x0e3a2a1f2146d86a604adc220b4967a898d7fe07\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "token",
  action: "tokeninfo",
  contractaddress: "0x0e3a2a1f2146d86a604adc220b4967a898d7fe07",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
const [token] = data.result;
console.log(token.tokenName, token.symbol, token.tokenPriceUSD);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "token",
    "action": "tokeninfo",
    "contractaddress": "0x0e3a2a1f2146d86a604adc220b4967a898d7fe07",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
token = response.json()["result"][0]
print(token["tokenName"], token["symbol"])
```
