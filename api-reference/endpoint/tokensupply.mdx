---
title: "Get ERC-20 Token Total Supply by Contract Address"
sidebarTitle: "Token Supply"
description: "Retrieve the current total circulating supply of any ERC-20 token by its contract address. Returns the value in the token's smallest unit."
---

Use this endpoint to fetch the current total supply of an ERC-20 token. The result is returned in the token's smallest unit (e.g., wei-equivalent for 18-decimal tokens), so divide by `10^decimals` to get the human-readable supply. You can find the token's decimals via the [tokeninfo](/api-reference/endpoint/tokeninfo) endpoint.

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="tokensupply">
  Set to `tokensupply` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The ERC-20 token contract address. Example: `0x57d90b64a1a57749b0f932f1a3395792e12e7055`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  The total token supply in the token's smallest unit (e.g., `21265524714464`).
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=tokensupply\
&contractaddress=0x57d90b64a1a57749b0f932f1a3395792e12e7055\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "tokensupply",
  contractaddress: "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
// Divide by 10^decimals to get human-readable supply
console.log("Total Supply (raw):", data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "tokensupply",
    "contractaddress": "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print("Total Supply (raw):", response.json()["result"])
```
