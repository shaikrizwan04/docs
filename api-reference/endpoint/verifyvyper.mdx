Use this endpoint to verify a Vyper contract deployed on any supported EVM chain. Send the Vyper source code in JSON format along with compiler settings. After submission, use the returned GUID to poll [checkverifystatus](/api-reference/endpoint/checkverifystatus) to confirm the verification completed successfully.

<Tip>
  Find all supported Vyper compiler versions at [etherscan.io/vyperversions](https://etherscan.io/vyperversions).
</Tip>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID of the network where the contract is deployed. Example: `1` for Ethereum mainnet. See [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="verifysourcecode">
  Set to `verifysourcecode` for this endpoint.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Request Body

Send the following fields as `application/x-www-form-urlencoded`.

<ParamField body="contractaddress" type="string" required>
  The address where the Vyper contract is deployed.
</ParamField>

<ParamField body="sourceCode" type="string" required>
  The Vyper source code in JSON format.
</ParamField>

<ParamField body="codeformat" type="string" required>
  Set to `vyper-json` for Vyper contracts.
</ParamField>

<ParamField body="contractname" type="string" required>
  The contract name including file path. Example: `contracts/Vault.vy:Vault`.
</ParamField>

<ParamField body="compilerversion" type="string" required>
  The Vyper compiler version used. Example: `vyper:0.4.0`. See [supported versions](https://etherscan.io/vyperversions).
</ParamField>

<ParamField body="optimizationUsed" type="string" required>
  Use `1` if compiler optimizations were enabled, `0` if not.
</ParamField>

<ParamField body="constructorArguments" type="string">
  ABI-encoded constructor arguments used at deployment. Optional.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request was accepted, `0` if it failed.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  A GUID string for the verification submission. Poll [checkverifystatus](/api-reference/endpoint/checkverifystatus) with this GUID to track the result.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl -X POST "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=verifysourcecode\
&apikey=YOUR_API_KEY" \
-d "contractaddress=0xdAC17F958D2ee523a2206206994597C13D831ec7" \
-d "sourceCode={...}" \
-d "codeformat=vyper-json" \
-d "contractname=contracts/Vault.vy:Vault" \
-d "compilerversion=vyper:0.4.0" \
-d "optimizationUsed=0"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "contract",
  action: "verifysourcecode",
  apikey: "YOUR_API_KEY",
});

const body = new URLSearchParams({
  contractaddress: "0xdAC17F958D2ee523a2206206994597C13D831ec7",
  sourceCode: JSON.stringify({ /* your vyper JSON */ }),
  codeformat: "vyper-json",
  contractname: "contracts/Vault.vy:Vault",
  compilerversion: "vyper:0.4.0",
  optimizationUsed: "0",
});

const response = await fetch(
  `https://api.etherscan.io/v2/api?${params}`,
  { method: "POST", body }
);
const data = await response.json();
console.log("Verification GUID:", data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "contract",
    "action": "verifysourcecode",
    "apikey": "YOUR_API_KEY",
}

payload = {
    "contractaddress": "0xdAC17F958D2ee523a2206206994597C13D831ec7",
    "sourceCode": "{ ... }",
    "codeformat": "vyper-json",
    "contractname": "contracts/Vault.vy:Vault",
    "compilerversion": "vyper:0.4.0",
    "optimizationUsed": "0",
}

response = requests.post(
    "https://api.etherscan.io/v2/api",
    params=params,
    data=payload
)
print("Verification GUID:", response.json()["result"])
```
