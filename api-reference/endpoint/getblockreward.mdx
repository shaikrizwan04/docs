---
title: "Get Block and Uncle Rewards for Any EVM Block Number"
sidebarTitle: "Block Reward"
description: "Retrieve the block reward and uncle block rewards for any mined block number across supported EVM chains. All reward values are returned in wei."
---

Use this endpoint to look up the mining reward issued for a specific block, including any uncle block rewards that were included. All reward values are returned in wei — use the [unit converter](https://etherscan.io/unitconverter) to convert to ETH.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="block">
  Set to `block` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getblockreward">
  Set to `getblockreward` for this endpoint.
</ParamField>

<ParamField query="blockno" type="integer" required>
  The block number to retrieve rewards for. Example: `2165403`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if no records were found or an error occurred.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result fields">
    <ResponseField name="blockNumber" type="string">
      The queried block number.
    </ResponseField>
    <ResponseField name="timeStamp" type="string">
      Unix timestamp (seconds) of when the block was mined.
    </ResponseField>
    <ResponseField name="blockMiner" type="string">
      Address of the miner who produced this block.
    </ResponseField>
    <ResponseField name="blockReward" type="string">
      Total block reward in wei, including uncle inclusion rewards.
    </ResponseField>
    <ResponseField name="uncles" type="array">
      List of uncle blocks included, each containing `miner`, `unclePosition`, and `blockreward` (in wei).
    </ResponseField>
    <ResponseField name="uncleInclusionReward" type="string">
      Additional reward earned by the miner for including uncle blocks, in wei.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=block\
&action=getblockreward\
&blockno=2165403\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "block",
  action: "getblockreward",
  blockno: "2165403",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "block",
    "action": "getblockreward",
    "blockno": 2165403,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
