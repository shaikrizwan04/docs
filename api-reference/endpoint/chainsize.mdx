---
title: "Get Ethereum Blockchain Size Over Date Range"
sidebarTitle: "chainsize"
description: "Returns the Ethereum blockchain size in bytes by day and client type (Geth/Parity) for default or archive sync modes. PRO endpoint."
---

Understanding how the Ethereum blockchain grows over time is essential for infrastructure planning — whether you're estimating storage costs for running a full node or projecting archive node requirements. This endpoint returns the chain data size in bytes for each day in the specified range, segmented by client type (Geth or Parity) and sync mode (default or archive).

<Note>
  This is a **PRO endpoint**, available to the [Standard Plan](/rate-limits) and above. Upgrade your API key to access it.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="chainsize">
  Set to `chainsize`.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format, e.g. `2019-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format, e.g. `2019-02-28`.
</ParamField>

<ParamField query="clienttype" type="string" required>
  The node client to query. Either `geth` or `parity`.
</ParamField>

<ParamField query="syncmode" type="string" required>
  The node sync mode. Either `default` (full) or `archive`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order. Use `asc` for oldest-first or `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily blockchain size measurements.

  <Expandable title="Result item fields">
    <ResponseField name="blockNumber" type="string">
      Block number at the end of the measured day.
    </ResponseField>
    <ResponseField name="chainTimeStamp" type="string">
      Date of the measurement in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="chainSize" type="string">
      Size of the chain data at this block, in bytes.
    </ResponseField>
    <ResponseField name="clientType" type="string">
      Client used for the measurement, e.g. `Geth` or `Parity`.
    </ResponseField>
    <ResponseField name="syncMode" type="string">
      Sync mode used, e.g. `Default` or `Archive`.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=chainsize\
&startdate=2019-02-01\
&enddate=2019-02-28\
&clienttype=geth\
&syncmode=default\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "chainsize",
  startdate: "2019-02-01",
  enddate: "2019-02-28",
  clienttype: "geth",
  syncmode: "default",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "chainsize",
    "startdate": "2019-02-01",
    "enddate": "2019-02-28",
    "clienttype": "geth",
    "syncmode": "default",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
