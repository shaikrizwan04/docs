Use this endpoint to look up a wallet's ERC-20 token balance at any historical block number. This is useful for governance snapshots, auditing past holdings, and backtesting strategies. The result is returned in the token's smallest unit.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="tokenbalancehistory">
  Set to `tokenbalancehistory` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The ERC-20 token contract address. Example: `0x57d90b64a1a57749b0f932f1a3395792e12e7055`.
</ParamField>

<ParamField query="address" type="string" required>
  The wallet or contract address to check the balance for. Example: `0xe04f27eb70e025b78871a2ad7eabe85e61212761`.
</ParamField>

<ParamField query="blockno" type="integer" required>
  The block number to check the balance at. Example: `8000000`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  The historical token balance at the given block, in the token's smallest unit.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=tokenbalancehistory\
&contractaddress=0x57d90b64a1a57749b0f932f1a3395792e12e7055\
&address=0xe04f27eb70e025b78871a2ad7eabe85e61212761\
&blockno=8000000\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "account",
  action: "tokenbalancehistory",
  contractaddress: "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
  address: "0xe04f27eb70e025b78871a2ad7eabe85e61212761",
  blockno: "8000000",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log("Balance at block 8000000:", data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "tokenbalancehistory",
    "contractaddress": "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
    "address": "0xe04f27eb70e025b78871a2ad7eabe85e61212761",
    "blockno": 8000000,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print("Balance at block 8000000:", response.json()["result"])
```
