---
title: "Get Latest ETH Price in BTC and USD"
sidebarTitle: "ethprice"
description: "Returns the latest price of ETH in both Bitcoin and US dollars, along with the Unix timestamps of each price update."
---

This endpoint returns the current market price of Ether denominated in two currencies: Bitcoin (ETH/BTC pair) and US dollars (ETH/USD pair). Each price comes with its own timestamp so you can verify data freshness. Use this endpoint to power price tickers, compute USD values for on-chain balances, or cross-reference against other price feeds.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="ethprice">
  Set to `ethprice`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request succeeded, `0` on error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="object">
  Latest ETH price data.

  <Expandable title="Result fields">
    <ResponseField name="ethbtc" type="string">
      Current price of 1 ETH expressed in Bitcoin.
    </ResponseField>
    <ResponseField name="ethbtc_timestamp" type="string">
      Unix timestamp (seconds) when the ETH/BTC price was last updated.
    </ResponseField>
    <ResponseField name="ethusd" type="string">
      Current price of 1 ETH expressed in US dollars.
    </ResponseField>
    <ResponseField name="ethusd_timestamp" type="string">
      Unix timestamp (seconds) when the ETH/USD price was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=ethprice\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "ethprice",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const { result } = await res.json();
console.log(`ETH/USD: $${result.ethusd}`);
console.log(`ETH/BTC: ${result.ethbtc} BTC`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "ethprice",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
result = r.json()["result"]
print(f"ETH/USD: ${result['ethusd']}")
print(f"ETH/BTC: {result['ethbtc']}")
```
