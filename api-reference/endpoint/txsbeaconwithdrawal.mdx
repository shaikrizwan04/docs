---
title: "Get Beacon Chain Withdrawals for a Validator Address"
sidebarTitle: "txsbeaconwithdrawal"
description: "Retrieve Ethereum beacon chain (consensus layer) withdrawals, optionally filtered by a withdrawal address, with block range and pagination."
---

Use this endpoint to fetch beacon chain withdrawals — the ETH payouts from Ethereum's consensus layer to execution layer addresses following EIP-4895. You can query all withdrawals across the chain within a block range, or filter to a specific withdrawal address to track payouts to a particular validator withdrawal credential. The amount is returned in gwei (not wei).

<Tip>
  Beacon chain withdrawals were introduced at the Ethereum Shanghai/Capella upgrade (block 17,034,870 on mainnet). Queries for blocks before that upgrade will return no results.
</Tip>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet. Check [supported chains](/supported-chains) for other chain IDs.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="txsBeaconWithdrawal">
  Set to `txsBeaconWithdrawal` for this endpoint.
</ParamField>

<ParamField query="address" type="string">
  Optional. The withdrawal address to filter results by. Omit to return all withdrawals within the specified block range.
</ParamField>

<ParamField query="startblock" type="integer" default="0">
  Starting block number to search from.
</ParamField>

<ParamField query="endblock" type="integer" default="999999999">
  Ending block number to search to.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination.
</ParamField>

<ParamField query="offset" type="integer" default="10">
  Number of records per page.
</ParamField>

<ParamField query="sort" type="string" default="asc">
  Sort order. Use `asc` for oldest first, `desc` for latest first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. See [common error messages](/common-error-messages) for error values.
</ResponseField>

<ResponseField name="result" type="array">
  An array of beacon chain withdrawal objects.

  <Expandable title="result[]">
    <ResponseField name="withdrawalIndex" type="string">Global sequential index of the withdrawal across all validators.</ResponseField>
    <ResponseField name="validatorIndex" type="string">Index of the validator that made the withdrawal.</ResponseField>
    <ResponseField name="address" type="string">Execution layer address that received the withdrawal.</ResponseField>
    <ResponseField name="amount" type="string">Amount withdrawn, in **gwei** (not wei). Divide by `10^9` to convert to ETH.</ResponseField>
    <ResponseField name="blockNumber" type="string">Block number in which the withdrawal was processed.</ResponseField>
    <ResponseField name="timestamp" type="string">Time of the withdrawal, as a UNIX timestamp in seconds.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=txsBeaconWithdrawal\
&address=0xB9D7934878B5FB9610B3fE8A5e441e8fad7E293f\
&startblock=17034870\
&endblock=999999999\
&page=1\
&offset=10\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "txsBeaconWithdrawal",
    "address": "0xB9D7934878B5FB9610B3fE8A5e441e8fad7E293f",
    "startblock": 17034870,
    "endblock": 999999999,
    "page": 1,
    "offset": 10,
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
