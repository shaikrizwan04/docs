---
title: "Get Blocks Validated by a Specific Validator Address"
sidebarTitle: "getminedblocks"
description: "Retrieve the list of blocks validated by a specific validator or miner address, including block number, timestamp, and block reward in wei."
---

Use this endpoint to retrieve blocks that were validated by a specific address. This is useful for tracking validator or miner activity, calculating historical block rewards, or auditing the block production history of a known validator node. The response includes the block number, timestamp, and reward earned for each block.

<Note>
  After Ethereum's Merge to Proof of Stake, blocks are proposed by validators rather than mined. Use `blocktype=blocks` for standard blocks on post-Merge chains. The `uncles` block type is only relevant for pre-Merge Ethereum blocks.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet or any chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getminedblocks">
  Set to `getminedblocks` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The validator or miner address to query, for example `0x9dd134d14d1e65f84b706d6f205cd5b1cd03a46b`.
</ParamField>

<ParamField query="blocktype" type="string" default="blocks">
  The type of blocks to return. Use `blocks` for full blocks. Use `uncles` to retrieve uncle blocks produced before the Ethereum Merge.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination.
</ParamField>

<ParamField query="offset" type="integer" default="10">
  Number of records per page.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. See [common error messages](/common-error-messages) for error values.
</ResponseField>

<ResponseField name="result" type="array">
  An array of validated block objects.

  <Expandable title="result[]">
    <ResponseField name="blockNumber" type="string">The number of the validated block.</ResponseField>
    <ResponseField name="timeStamp" type="string">Time the block was validated, as a UNIX timestamp in seconds.</ResponseField>
    <ResponseField name="blockReward" type="string">Reward earned for validating this block, in wei. Divide by `10^18` to convert to ETH. Use the [unit converter](https://etherscan.io/unitconverter) for other denominations.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=getminedblocks\
&address=0x9dd134d14d1e65f84b706d6f205cd5b1cd03a46b\
&blocktype=blocks\
&page=1\
&offset=10\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "getminedblocks",
    "address": "0x9dd134d14d1e65f84b706d6f205cd5b1cd03a46b",
    "blocktype": "blocks",
    "page": 1,
    "offset": 10,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
