title: "Check the Status of a Proxy Contract Verification Request"

---

Use this endpoint to check whether a proxy contract verification has completed. Pass the GUID returned by [verifyproxycontract](/api-reference/endpoint/verifyproxycontract) and poll until you receive a terminal result. A successful response links the proxy to its detected implementation contract on Etherscan.

<Tip>
  Poll every few seconds after submitting proxy verification. Verification typically resolves within 30 seconds for already-indexed contracts.
</Tip>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID you submitted the proxy verification on. Example: `1` for Ethereum mainnet. See [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="checkproxyverification">
  Set to `checkproxyverification` for this endpoint.
</ParamField>

<ParamField query="guid" type="string" required>
  The GUID returned by your [verifyproxycontract](/api-reference/endpoint/verifyproxycontract) submission. Example: `gwgrrnfy56zf6vc1fljuejwg6pelnc5yns6fg6y2i6zfpgzquz`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if there was an error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or `NOTOK` for failures.
</ResponseField>

<ResponseField name="result" type="string">
  A human-readable result message. Returns a success message on completion or a descriptive error if verification failed, for example if the proxy contract is not yet source-verified.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=checkproxyverification\
&guid=gwgrrnfy56zf6vc1fljuejwg6pelnc5yns6fg6y2i6zfpgzquz\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "contract",
  action: "checkproxyverification",
  guid: "gwgrrnfy56zf6vc1fljuejwg6pelnc5yns6fg6y2i6zfpgzquz",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "contract",
    "action": "checkproxyverification",
    "guid": "gwgrrnfy56zf6vc1fljuejwg6pelnc5yns6fg6y2i6zfpgzquz",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
</CodeGroup>
