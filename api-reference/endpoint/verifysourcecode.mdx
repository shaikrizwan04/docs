Use this endpoint to programmatically verify a Solidity contract's source code on Etherscan. Send the source code alongside compiler settings as a `POST` request with `application/x-www-form-urlencoded` body. After submission, you receive a GUID that you can poll with [checkverifystatus](/api-reference/endpoint/checkverifystatus) to track the result.

<Tip>
  After submitting, poll [Check Source Code Verification Status](/api-reference/endpoint/checkverifystatus) every few seconds with the returned GUID until you receive `Pass - Verified` or an error.
</Tip>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID of the network where the contract is deployed. Example: `1` for Ethereum mainnet. See [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="verifysourcecode">
  Set to `verifysourcecode` for this endpoint.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Request Body

Send the following fields as `application/x-www-form-urlencoded`.

<ParamField body="contractaddress" type="string" required>
  The address where the contract is deployed. Example: `0xdAC17F958D2ee523a2206206994597C13D831ec7`.
</ParamField>

<ParamField body="sourceCode" type="string" required>
  The Solidity source code to verify. For `solidity-standard-json-input`, pass the full JSON input object as a string.
</ParamField>

<ParamField body="codeformat" type="string">
  The source format. Use `solidity-single-file` for a single `.sol` file, or `solidity-standard-json-input` for JSON input. Defaults to single-file if omitted.
</ParamField>

<ParamField body="contractname" type="string" required>
  The contract name. For standard JSON input, include the file path: `contracts/Token.sol:Token`.
</ParamField>

<ParamField body="compilerversion" type="string" required>
  The Solidity compiler version used, e.g. `v0.8.24+commit.e11b9ed9`. See [supported versions](https://etherscan.io/solcversions).
</ParamField>

<ParamField body="optimizationUsed" type="string">
  Required for `solidity-single-file`. Use `1` if optimization was enabled, `0` if not.
</ParamField>

<ParamField body="runs" type="string">
  Number of optimizer runs. Required when `optimizationUsed` is `1`. Example: `200`.
</ParamField>

<ParamField body="constructorArguments" type="string">
  ABI-encoded constructor arguments used at deployment. Example: `00000000000000000000000074271f2282ed7ee35c166122a60c9830354be42a`.
</ParamField>

<ParamField body="evmVersion" type="string">
  Target EVM version. Use `default` or a named version such as `byzantium` or `shanghai`.
</ParamField>

<ParamField body="licenseType" type="string">
  Numeric license type to associate with the source code. Example: `3` for MIT. See [license types](https://etherscan.io/contract-license-types).
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request was accepted, `0` if it failed.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  A GUID string for the verification submission. Use this with [checkverifystatus](/api-reference/endpoint/checkverifystatus) to poll the result.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl -X POST "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=verifysourcecode\
&apikey=YOUR_API_KEY" \
-d "contractaddress=0xdAC17F958D2ee523a2206206994597C13D831ec7" \
-d "sourceCode=pragma solidity 0.8.24; contract MyToken { ... }" \
-d "codeformat=solidity-single-file" \
-d "contractname=MyToken" \
-d "compilerversion=v0.8.24%2Bcommit.e11b9ed9" \
-d "optimizationUsed=1" \
-d "runs=200" \
-d "licenseType=3"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "contract",
  action: "verifysourcecode",
  apikey: "YOUR_API_KEY",
});

const body = new URLSearchParams({
  contractaddress: "0xdAC17F958D2ee523a2206206994597C13D831ec7",
  sourceCode: "pragma solidity 0.8.24; contract MyToken { ... }",
  codeformat: "solidity-single-file",
  contractname: "MyToken",
  compilerversion: "v0.8.24+commit.e11b9ed9",
  optimizationUsed: "1",
  runs: "200",
  licenseType: "3",
});

const response = await fetch(
  `https://api.etherscan.io/v2/api?${params}`,
  { method: "POST", body }
);
const data = await response.json();
const guid = data.result;
console.log("Verification GUID:", guid);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "contract",
    "action": "verifysourcecode",
    "apikey": "YOUR_API_KEY",
}

payload = {
    "contractaddress": "0xdAC17F958D2ee523a2206206994597C13D831ec7",
    "sourceCode": "pragma solidity 0.8.24; contract MyToken { ... }",
    "codeformat": "solidity-single-file",
    "contractname": "MyToken",
    "compilerversion": "v0.8.24+commit.e11b9ed9",
    "optimizationUsed": "1",
    "runs": "200",
    "licenseType": "3",
}

response = requests.post(
    "https://api.etherscan.io/v2/api",
    params=params,
    data=payload
)
guid = response.json()["result"]
print("Verification GUID:", guid)
```
