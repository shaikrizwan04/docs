Use this endpoint to fetch a complete list of ERC-20 token holdings for any wallet or contract address. Each record includes the token contract address, name, symbol, raw quantity, number of decimals, and current USD price — giving you everything you need to build portfolio views and wallet summaries in a single call.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="addresstokenbalance">
  Set to `addresstokenbalance` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The wallet or contract address to check for token holdings. Example: `0x983e3660c0bE01991785F80f266A84B911ab59b0`.
</ParamField>

<ParamField query="page" type="integer">
  Page number for paginated results. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of records per page. Example: `100`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of ERC-20 token holdings.
  <Expandable title="result item fields">
    <ResponseField name="TokenAddress" type="string">
      Contract address of the ERC-20 token.
    </ResponseField>
    <ResponseField name="TokenName" type="string">
      Full name of the token.
    </ResponseField>
    <ResponseField name="TokenSymbol" type="string">
      Token ticker symbol.
    </ResponseField>
    <ResponseField name="TokenQuantity" type="string">
      Amount held, in the token's smallest unit.
    </ResponseField>
    <ResponseField name="TokenDivisor" type="string">
      Number of decimal places the token uses.
    </ResponseField>
    <ResponseField name="TokenPriceUSD" type="string">
      Current token price in US dollars.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=addresstokenbalance\
&address=0x983e3660c0bE01991785F80f266A84B911ab59b0\
&page=1\
&offset=100\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "account",
  action: "addresstokenbalance",
  address: "0x983e3660c0bE01991785F80f266A84B911ab59b0",
  page: "1",
  offset: "100",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "addresstokenbalance",
    "address": "0x983e3660c0bE01991785F80f266A84B911ab59b0",
    "page": 1,
    "offset": 100,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
