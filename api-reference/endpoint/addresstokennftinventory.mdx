---
title: "Get ERC-721 Token Inventory for an Address and Contract"
sidebarTitle: "NFT Inventory"
description: "Retrieve the specific ERC-721 token IDs owned by an address for a given NFT contract. Paginated. Requires a Standard plan API key."
---

Use this endpoint to get the exact token IDs an address owns within a specific ERC-721 collection. While the [addresstokennftbalance](/api-reference/endpoint/addresstokennftbalance) endpoint gives you collection-level counts, this endpoint drills down to individual token IDs — useful for building NFT inventory views, verifying ownership, and querying token-specific metadata.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="addresstokennftinventory">
  Set to `addresstokennftinventory` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The wallet or contract address to check for NFT inventory. Example: `0x123432244443b54409430979df8333f9308a6040`.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The ERC-721 collection contract address to filter by. Example: `0xed5af388653567af2f388e6224dc7c4b3241c544`.
</ParamField>

<ParamField query="page" type="integer">
  Page number for paginated results. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of records per page. Example: `100`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of token inventory records.
  <Expandable title="result item fields">
    <ResponseField name="TokenAddress" type="string">
      Contract address of the ERC-721 collection.
    </ResponseField>
    <ResponseField name="TokenId" type="string">
      Unique identifier of the specific NFT owned by the address.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=addresstokennftinventory\
&address=0x123432244443b54409430979df8333f9308a6040\
&contractaddress=0xed5af388653567af2f388e6224dc7c4b3241c544\
&page=1\
&offset=100\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "account",
  action: "addresstokennftinventory",
  address: "0x123432244443b54409430979df8333f9308a6040",
  contractaddress: "0xed5af388653567af2f388e6224dc7c4b3241c544",
  page: "1",
  offset: "100",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
const tokenIds = data.result.map((item) => item.TokenId);
console.log("Owned token IDs:", tokenIds);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "addresstokennftinventory",
    "address": "0x123432244443b54409430979df8333f9308a6040",
    "contractaddress": "0xed5af388653567af2f388e6224dc7c4b3241c544",
    "page": 1,
    "offset": 100,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
token_ids = [item["TokenId"] for item in response.json()["result"]]
print("Owned token IDs:", token_ids)
```
