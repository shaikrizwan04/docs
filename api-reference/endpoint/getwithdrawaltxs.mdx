---
title: "Get L2→L1 Withdrawal Transactions by Address"
sidebarTitle: "getwithdrawaltxs"
description: "Returns cross-chain withdrawal transactions from an L2 network back to Ethereum L1 for a specified address, including withdrawal status."
---

Withdrawals from an L2 chain back to Ethereum mainnet go through a multi-step challenge process. This endpoint retrieves those outbound L2-to-L1 withdrawal records for a given address, including the current status of each withdrawal, the originating L2 transaction hash, and the L1 transaction that finalizes the withdrawal (once it is executed). Use it to monitor pending withdrawals or to build cross-chain accounting tools.

<Note>
  This endpoint is supported on **Arbitrum One** (`chainid=42161`), **Arbitrum Sepolia** (`chainid=421614`), **OP Mainnet** (`chainid=10`), and **OP Sepolia** (`chainid=11155420`).
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The L2 chain to query. Use `10` for Optimism or `42161` for Arbitrum. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account`.
</ParamField>

<ParamField query="action" type="string" required default="getwithdrawaltxs">
  Set to `getwithdrawaltxs`.
</ParamField>

<ParamField query="address" type="string" required>
  The address to query for cross-chain withdrawal transactions.
</ParamField>

<ParamField query="page" type="integer">
  Page number for pagination. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of records per page.
</ParamField>

<ParamField query="sort" type="string">
  Sort order: `asc` for oldest-first, `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if records were returned, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of L2 withdrawal transaction objects.

  <Expandable title="Withdrawal transaction fields">
    <ResponseField name="blockNumber" type="string">Block number on the L2 chain.</ResponseField>
    <ResponseField name="timeStamp" type="string">Unix timestamp of the transaction in seconds.</ResponseField>
    <ResponseField name="hash" type="string">L2 transaction hash.</ResponseField>
    <ResponseField name="from" type="string">Address that initiated the withdrawal.</ResponseField>
    <ResponseField name="to" type="string">Recipient address.</ResponseField>
    <ResponseField name="value" type="string">Native token amount, in wei.</ResponseField>
    <ResponseField name="gasUsed" type="string">Gas consumed by the transaction.</ResponseField>
    <ResponseField name="isError" type="string">`0` for success, `1` for failure.</ResponseField>
    <ResponseField name="status" type="string">Current withdrawal status, e.g. `Waiting`, `Ready`, `Finalized`.</ResponseField>
    <ResponseField name="L1transactionhash" type="string">Hash of the L1 transaction that finalized the withdrawal. Empty until finalized.</ResponseField>
    <ResponseField name="tokenAddress" type="string">Address of the token withdrawn.</ResponseField>
    <ResponseField name="tokenValue" type="string">Amount of tokens withdrawn, in the token's smallest unit.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=10\
&module=account\
&action=getwithdrawaltxs\
&address=0x80f3950a4d371c43360f292a4170624abd9eed03\
&page=1\
&offset=100\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "10",
  module: "account",
  action: "getwithdrawaltxs",
  address: "0x80f3950a4d371c43360f292a4170624abd9eed03",
  page: "1",
  offset: "100",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "10",
    "module": "account",
    "action": "getwithdrawaltxs",
    "address": "0x80f3950a4d371c43360f292a4170624abd9eed03",
    "page": 1,
    "offset": 100,
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
