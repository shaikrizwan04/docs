---
title: "Get Native Token Balances for Up to 20 Wallet Addresses"
sidebarTitle: "balancemulti"
description: "Retrieve native token balances for up to 20 addresses in a single API call. Returns an array of account-balance pairs, each balance in wei."
---

Use this endpoint to fetch native token balances for up to 20 addresses in a single request, rather than making a separate call for each address. This is useful when you need to display balances for a list of wallets or scan multiple accounts at once. Each address in the response is paired with its balance in wei.

<Tip>
  Batching up to 20 addresses per call reduces round-trips and helps you stay within rate limits. For more than 20 addresses, split them into groups and send multiple requests.
</Tip>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet, `137` for Polygon, `42161` for Arbitrum, or any chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="balancemulti">
  Set to `balancemulti` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  A comma-separated list of addresses to query, up to a maximum of 20 addresses per call. For example: `0xaddr1,0xaddr2,0xaddr3`.
</ParamField>

<ParamField query="tag" type="string" default="latest">
  The block parameter to use. Pass `latest` for the most recent block. Also accepts a specific block number in hex format (e.g., `0x10d4f`) for any block within the last 128 blocks.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if an error occurred or no records were found.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. On error, contains a description such as `NOTOK`. See [common error messages](/common-error-messages).
</ResponseField>

<ResponseField name="result" type="array">
  An array of objects, one per queried address.

  <Expandable title="result[]">
    <ResponseField name="account" type="string">
      The queried address.
    </ResponseField>
    <ResponseField name="balance" type="string">
      Account balance in wei. Divide by `10^18` to convert to the native token's base unit. Use the [unit converter](https://etherscan.io/unitconverter) for other denominations.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=balancemulti\
&address=0xddbd2b932c763ba5b1b7ae3b362eac3e8d40121a,0x63a9975ba31b0b9626b34300f7f627147df1f526,0x198ef1ec325a96cc354c7266a038be8b5c558f67\
&tag=latest\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "balancemulti",
    "address": "0xddbd2b932c763ba5b1b7ae3b362eac3e8d40121a,0x63a9975ba31b0b9626b34300f7f627147df1f526,0x198ef1ec325a96cc354c7266a038be8b5c558f67",
    "tag": "latest",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```

```javascript JavaScript

```
