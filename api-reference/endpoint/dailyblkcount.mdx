---
title: "Get Daily Block Count and Rewards"
sidebarTitle: "Daily Block Count"
description: "Retrieve the daily count of mined blocks and the total block rewards issued per day over a specified date range."
---

Use this endpoint to track daily block production and associated rewards over a given period. Each result includes the number of blocks mined on that UTC day and the total ETH rewards issued to miners. This data is useful for analyzing network activity, miner income, and emission trends over time.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="dailyblkcount">
  Set to `dailyblkcount` for this endpoint.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format. Example: `2019-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format. Example: `2019-02-28`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order for results. Use `asc` for ascending or `desc` for descending. Defaults to `asc`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily block count and reward data points.
  <Expandable title="result item fields">
    <ResponseField name="UTCDate" type="string">
      The date of the data point in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="unixTimeStamp" type="string">
      Unix timestamp (seconds) for the start of that UTC day.
    </ResponseField>
    <ResponseField name="blockCount" type="number">
      Number of blocks mined on that day.
    </ResponseField>
    <ResponseField name="blockRewards_Eth" type="string">
      Total block rewards issued on that day, in ETH.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=dailyblkcount\
&startdate=2019-02-01\
&enddate=2019-02-28\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "dailyblkcount",
  startdate: "2019-02-01",
  enddate: "2019-02-28",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "dailyblkcount",
    "startdate": "2019-02-01",
    "enddate": "2019-02-28",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
