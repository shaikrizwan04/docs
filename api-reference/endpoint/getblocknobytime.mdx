---
title: "Get the Closest EVM Block Number to a Unix Timestamp"
sidebarTitle: "Block by Timestamp"
description: "Retrieve the block number closest to a given Unix timestamp on any supported EVM chain. Use the closest parameter to select before or after."
---

Use this endpoint to convert a Unix timestamp into a block number. Specify `before` to get the last block mined at or before the timestamp, or `after` to get the first block mined at or after it. This is commonly used when you need to query on-chain state as it existed at a specific moment in time.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="block">
  Set to `block` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getblocknobytime">
  Set to `getblocknobytime` for this endpoint.
</ParamField>

<ParamField query="timestamp" type="integer" required>
  Unix timestamp in seconds to look up. Example: `1578638524`.
</ParamField>

<ParamField query="closest" type="string" required>
  Whether to return the block `before` or `after` the given timestamp. Accepted values: `before`, `after`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  The block number closest to the provided timestamp, based on the `closest` parameter.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=block\
&action=getblocknobytime\
&timestamp=1578638524\
&closest=before\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "block",
  action: "getblocknobytime",
  timestamp: "1578638524",
  closest: "before",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result); // "9251482"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "block",
    "action": "getblocknobytime",
    "timestamp": 1578638524,
    "closest": "before",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
