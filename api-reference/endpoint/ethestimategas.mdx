---
title: "Estimate Gas for a Transaction"
sidebarTitle: "eth_estimateGas"
description: "Estimates the amount of gas a transaction will consume when executed against the current chain state, without broadcasting it."
---

This endpoint mirrors the standard `eth_estimateGas` JSON-RPC method. It simulates a transaction against the current state of the chain and returns an estimate of the gas units needed for successful execution. Use this before broadcasting a transaction to set an appropriate gas limit — setting it too low causes the transaction to revert out of gas, while setting it too high wastes ETH on unused gas capacity.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface. The estimate may vary slightly from actual execution due to state changes between the estimate and the actual transaction inclusion.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_estimateGas">
  Set to `eth_estimateGas`.
</ParamField>

<ParamField query="to" type="string" required>
  The recipient address or contract to simulate the call against.
</ParamField>

<ParamField query="data" type="string">
  ABI-encoded calldata for the function call, as a `0x`-prefixed hex string.
</ParamField>

<ParamField query="value" type="string">
  Amount of ETH to include in the simulated transaction, in wei (hex-encoded).
</ParamField>

<ParamField query="from" type="string">
  Sender address for the simulation. Affects behavior of `msg.sender` checks.
</ParamField>

<ParamField query="gas" type="string">
  Gas limit to use for the simulation, hex-encoded. Defaults to the block gas limit.
</ParamField>

<ParamField query="gasPrice" type="string">
  Gas price for the simulation, in wei (hex-encoded).
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="string">
  Estimated gas units required, as a `0x`-prefixed hex string.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_estimateGas\
&to=0xf0109fc8df283027b6285cc889f5aa624eac1f55\
&value=0x186a0\
&gasPrice=0x9184e72a000\
&gas=0x55555\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_estimateGas",
  to: "0xf0109fc8df283027b6285cc889f5aa624eac1f55",
  value: "0x186a0",
  gasPrice: "0x9184e72a000",
  gas: "0x55555",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const { result } = await res.json();
console.log(`Estimated gas: ${parseInt(result, 16)}`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_estimateGas",
    "to": "0xf0109fc8df283027b6285cc889f5aa624eac1f55",
    "value": "0x186a0",
    "gasPrice": "0x9184e72a000",
    "gas": "0x55555",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
estimated = int(r.json()["result"], 16)
print(f"Estimated gas: {estimated}")
```
</CodeGroup>

```json Example Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x5208"
}
```

<Tip>
  A standard ETH transfer always uses exactly `21000` gas (`0x5208`). Contract interactions use significantly more — always estimate before setting your gas limit.
</Tip>
