---
title: "Get Transaction by Block Number and Index Position"
sidebarTitle: "eth_getTransactionByBlockNumberAndIndex"
description: "Returns the full transaction object at a specific index position within a block identified by block number, mirroring the standard JSON-RPC method."
---

This endpoint mirrors the standard `eth_getTransactionByBlockNumberAndIndex` JSON-RPC method. When you know the block number and the position of a transaction within that block, you can retrieve the full transaction object directly — without needing the transaction hash. This is useful when iterating over all transactions in a block in order.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_getTransactionByBlockNumberAndIndex">
  Set to `eth_getTransactionByBlockNumberAndIndex`.
</ParamField>

<ParamField query="tag" type="string" required>
  Hex-encoded block number, e.g. `0x10d4f`, or `latest`.
</ParamField>

<ParamField query="index" type="string" required>
  Hex-encoded transaction index within the block. The first transaction is `0x0`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="object">
  Transaction object at the specified position, or `null` if not found. Contains the same fields as `eth_getTransactionByHash`: hash, nonce, blockHash, blockNumber, transactionIndex, from, to, value, gasPrice, gas, input.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_getTransactionByBlockNumberAndIndex\
&tag=0x10d4f\
&index=0x0\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_getTransactionByBlockNumberAndIndex",
  tag: "0x10d4f",
  index: "0x0",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_getTransactionByBlockNumberAndIndex",
    "tag": "0x10d4f",
    "index": "0x0",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
