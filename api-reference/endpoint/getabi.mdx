---
title: "Get Contract ABI for Verified Contracts"
sidebarTitle: "Get ABI"
description: "Retrieve the ABI for any verified smart contract by its address. Only contracts that have been source-verified on Etherscan return a result."
---

Use this endpoint to fetch the JSON ABI of a verified smart contract. The ABI is returned as a JSON-encoded string that you can parse and use directly with libraries like ethers.js or web3.py to interact with the contract programmatically. If the contract has not been verified, the API returns an error result.

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getabi">
  Set to `getabi` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The contract address to fetch the ABI for. Example: `0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  The contract ABI as a JSON-encoded string. Parse this string to get the full ABI array. Returns an error message if the contract is not verified.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=getabi\
&address=0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "contract",
  action: "getabi",
  address: "0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
const abi = JSON.parse(data.result);
console.log(abi);
```

```python Python
import requests
import json

params = {
    "chainid": "1",
    "module": "contract",
    "action": "getabi",
    "address": "0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
abi = json.loads(response.json()["result"])
print(abi)
```
</CodeGroup>

<Tip>
  The `result` field is a JSON string — call `JSON.parse()` (JavaScript) or `json.loads()` (Python) on it to get the usable ABI array.
</Tip>
