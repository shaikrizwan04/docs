title: "Get the Latest Block Number via eth_blockNumber Proxy"
sidebarTitle: "eth_blockNumber"

---

This endpoint mirrors the standard Ethereum JSON-RPC `eth_blockNumber` method, returning the current latest block number as a hexadecimal string. Use it to determine the chain's current head before making block-range queries, or to detect how far behind a cached block number has fallen.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface. Responses follow the same encoding conventions as direct node calls — numeric values are returned as `0x`-prefixed hex strings.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_blockNumber">
  Set to `eth_blockNumber`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="string">
  The latest block number as a `0x`-prefixed hexadecimal string. Convert to decimal with `parseInt(result, 16)`.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_blockNumber\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_blockNumber",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(`Latest block: ${parseInt(data.result, 16)}`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_blockNumber",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
latest = int(r.json()["result"], 16)
print(f"Latest block: {latest}")
```
</CodeGroup>
