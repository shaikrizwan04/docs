---
title: "Get Contract Source Code for Verified Smart Contracts"
sidebarTitle: "Get Source Code"
description: "Retrieve the full source code, ABI, compiler settings, and proxy details for any verified smart contract by its deployed address on any chain."
---

Use this endpoint to access all verification metadata for a smart contract. The response includes the source code, ABI, compiler version, optimization settings, constructor arguments, EVM version, library dependencies, license type, and proxy/implementation details. If the contract is a proxy, the `Implementation` field points to its logic contract address.

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="contract">
  Set to `contract` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getsourcecode">
  Set to `getsourcecode` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The contract address to fetch source code for. Example: `0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array containing a single object with the contract's verification details.
  <Expandable title="result item fields">
    <ResponseField name="SourceCode" type="string">
      Verified source code of the contract. Empty if unverified.
    </ResponseField>
    <ResponseField name="ABI" type="string">
      Contract ABI as a JSON-encoded string. Returns an error message if unverified.
    </ResponseField>
    <ResponseField name="ContractName" type="string">
      Name of the contract.
    </ResponseField>
    <ResponseField name="CompilerVersion" type="string">
      Compiler version used during compilation, e.g. `v0.8.24+commit.e11b9ed9`.
    </ResponseField>
    <ResponseField name="CompilerType" type="string">
      Type of compiler used, such as `solc` or `vyper`.
    </ResponseField>
    <ResponseField name="OptimizationUsed" type="string">
      `1` if compiler optimization was enabled, `0` otherwise.
    </ResponseField>
    <ResponseField name="Runs" type="string">
      Number of optimizer runs configured.
    </ResponseField>
    <ResponseField name="ConstructorArguments" type="string">
      ABI-encoded constructor arguments used at deployment. Empty if none.
    </ResponseField>
    <ResponseField name="EVMVersion" type="string">
      Target EVM version used during compilation. Returns `Default` if unset.
    </ResponseField>
    <ResponseField name="Library" type="string">
      Libraries linked during compilation. Empty if none.
    </ResponseField>
    <ResponseField name="ContractFileName" type="string">
      Main source file name for multi-file verifications.
    </ResponseField>
    <ResponseField name="LicenseType" type="string">
      Open source license declared for the source code.
    </ResponseField>
    <ResponseField name="Proxy" type="string">
      `1` if the contract is a proxy, `0` otherwise.
    </ResponseField>
    <ResponseField name="Implementation" type="string">
      Address of the implementation contract, if this is a proxy. Empty otherwise.
    </ResponseField>
    <ResponseField name="SwarmSource" type="string">
      Swarm source hash of the compiler metadata, if present.
    </ResponseField>
    <ResponseField name="SimilarMatch" type="string">
      Address of another verified contract with matching source code, if found.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=contract\
&action=getsourcecode\
&address=0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "contract",
  action: "getsourcecode",
  address: "0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
const [contract] = data.result;
console.log(contract.ContractName, contract.CompilerVersion);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "contract",
    "action": "getsourcecode",
    "address": "0xBB9bc244D798123fDe783fCc1C72d3Bb8C189413",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
contract = response.json()["result"][0]
print(contract["ContractName"], contract["CompilerVersion"])
```
