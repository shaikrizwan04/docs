---
title: "Get Total Circulating ETH Supply in Wei from Rewards"
sidebarTitle: "ethsupply"
description: "Returns total circulating supply of Ether in wei from block rewards, excluding ETH2 staking rewards, EIP-1559 burns, and Beacon Chain withdrawals."
---

This endpoint returns the total supply of Ether minted from block rewards, expressed in wei. Note that this figure excludes two important adjustments introduced after the Merge: ETH staked on the Beacon Chain and fees burned by EIP-1559. For a comprehensive view of all supply-side factors, use the [ethsupply2](/api-reference/endpoint/ethsupply2) endpoint instead.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="ethsupply">
  Set to `ethsupply`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request succeeded, `0` on error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  Total ETH supply from block rewards, expressed in wei. Divide by 10^18 to convert to ETH.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=ethsupply\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "ethsupply",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
const ethSupply = BigInt(data.result) / BigInt(1e18);
console.log(`ETH supply: ${ethSupply} ETH`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "ethsupply",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
supply_wei = int(r.json()["result"])
print(f"ETH supply: {supply_wei / 1e18:.2f} ETH")
```
</CodeGroup>

```json Example Response
{
  "status": "1",
  "message": "OK",
  "result": "122373866217800000000000000"
}
```

<Tip>
  The result is in wei (1 ETH = 10^18 wei). Use the [Etherscan Unit Converter](https://etherscan.io/unitconverter) or divide by `10**18` in your code to express this in ETH.
</Tip>
