---
title: "Get ERC-20 Token Balance for a Wallet or Contract Address"
sidebarTitle: "Token Balance"
description: "Retrieve the current ERC-20 token balance held by a specific address for a given token contract. Returns the value in the token's smallest unit."
---

Use this endpoint to check how many ERC-20 tokens a specific address currently holds. Provide both the token contract address and the holder's address. The returned balance is in the token's smallest unit — divide by `10^decimals` to get the human-readable amount. Use the `tag` parameter to specify the block context; set it to `latest` to get the current balance.

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="tokenbalance">
  Set to `tokenbalance` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The ERC-20 token contract address. Example: `0x57d90b64a1a57749b0f932f1a3395792e12e7055`.
</ParamField>

<ParamField query="address" type="string" required>
  The wallet or contract address to check the token balance for. Example: `0xe04f27eb70e025b78871a2ad7eabe85e61212761`.
</ParamField>

<ParamField query="tag" type="string">
  Block parameter context. Use `latest` for the most recent block. Defaults to `latest`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  The token balance held by the address, in the token's smallest unit.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=tokenbalance\
&contractaddress=0x57d90b64a1a57749b0f932f1a3395792e12e7055\
&address=0xe04f27eb70e025b78871a2ad7eabe85e61212761\
&tag=latest\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "account",
  action: "tokenbalance",
  contractaddress: "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
  address: "0xe04f27eb70e025b78871a2ad7eabe85e61212761",
  tag: "latest",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log("Token balance (raw):", data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "tokenbalance",
    "contractaddress": "0x57d90b64a1a57749b0f932f1a3395792e12e7055",
    "address": "0xe04f27eb70e025b78871a2ad7eabe85e61212761",
    "tag": "latest",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print("Token balance (raw):", response.json()["result"])
```
