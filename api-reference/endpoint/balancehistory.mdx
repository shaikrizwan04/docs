---
title: "Get Historical Native Token Balance for an Address"
sidebarTitle: "balancehistory"
description: "Retrieve the native token balance of an address at a specific block height. Useful for point-in-time balance snapshots and historical analysis."
---

Use this endpoint to look up the native token balance of an address at any historical block height, all the way back to the genesis block. This is useful for auditing, reporting, and any use case where you need a point-in-time snapshot of what an address held at a specific moment in the chain's history.

<Note>
  This is a **PRO endpoint**, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls per second** regardless of your API Pro tier.
</Warning>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet or any other chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="balancehistory">
  Set to `balancehistory` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The address to query, for example `0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae`.
</ParamField>

<ParamField query="blockno" type="integer" required>
  The block number at which to check the balance. You can query any block from the current chain height all the way back to block `0` (genesis).
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if an error occurred or no records were found.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. On error, contains a description such as `NOTOK`. See [common error messages](/common-error-messages).
</ResponseField>

<ResponseField name="result" type="string">
  The account balance at the given block, in wei. Divide by `10^18` to convert to the native token's base unit. Use the [unit converter](https://etherscan.io/unitconverter) for other denominations.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=balancehistory\
&address=0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae\
&blockno=8000000\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "balancehistory",
    "address": "0xde0b295669a9fd93d5f28d9ec85e40f4cb697bae",
    "blockno": 8000000,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
