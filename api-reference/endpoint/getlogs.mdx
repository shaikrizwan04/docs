---
title: "Get Event Logs Emitted by a Smart Contract Address"
sidebarTitle: "getLogs"
description: "Retrieve event logs emitted by a smart contract address with optional block range filtering. All numeric fields are returned as hex-encoded strings."
---

Event logs are the primary mechanism smart contracts use to emit data to external consumers. This endpoint returns all logs from a specific contract address, letting you filter by block range and paginate through large result sets. All numeric fields in the response — including block numbers, gas values, and timestamps — are hex-encoded strings.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="logs">
  Set to `logs`.
</ParamField>

<ParamField query="action" type="string" required default="getLogs">
  Set to `getLogs`.
</ParamField>

<ParamField query="address" type="string" required>
  The contract address to retrieve logs from, e.g. `0xbd3531da5cf5857e7cfaa92426877b022e612cf8`.
</ParamField>

<ParamField query="fromBlock" type="integer" required>
  The starting block number (inclusive) for the query range.
</ParamField>

<ParamField query="toBlock" type="integer" required>
  The ending block number (inclusive) for the query range.
</ParamField>

<ParamField query="page" type="integer">
  The page number when paginating through results. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  The number of records returned per page. Maximum is `1000`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if it returned no records or encountered an error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of event log objects.

  <Expandable title="Log object fields">
    <ResponseField name="address" type="string">
      Address of the contract that emitted the log.
    </ResponseField>
    <ResponseField name="topics" type="array">
      Array of indexed log topics. The first element is the keccak256 hash of the event signature.
    </ResponseField>
    <ResponseField name="data" type="string">
      Non-indexed event data encoded as a hex string.
    </ResponseField>
    <ResponseField name="blockNumber" type="string">
      Block number where the log was recorded, as a hex string.
    </ResponseField>
    <ResponseField name="blockHash" type="string">
      Hash of the block containing the log.
    </ResponseField>
    <ResponseField name="timeStamp" type="string">
      Unix timestamp of the block, as a hex string.
    </ResponseField>
    <ResponseField name="gasPrice" type="string">
      Gas price of the transaction that produced the log, in wei (hex).
    </ResponseField>
    <ResponseField name="gasUsed" type="string">
      Gas consumed by the transaction, as a hex string.
    </ResponseField>
    <ResponseField name="logIndex" type="string">
      Index position of this log within the block, as a hex string.
    </ResponseField>
    <ResponseField name="transactionHash" type="string">
      Hash of the transaction that produced the log.
    </ResponseField>
    <ResponseField name="transactionIndex" type="string">
      Index of the transaction within the block, as a hex string.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=logs\
&action=getLogs\
&address=0xbd3531da5cf5857e7cfaa92426877b022e612cf8\
&fromBlock=12878196\
&toBlock=12878196\
&page=1\
&offset=100\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "logs",
  action: "getLogs",
  address: "0xbd3531da5cf5857e7cfaa92426877b022e612cf8",
  fromBlock: "12878196",
  toBlock: "12878196",
  page: "1",
  offset: "100",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "logs",
    "action": "getLogs",
    "address": "0xbd3531da5cf5857e7cfaa92426877b022e612cf8",
    "fromBlock": 12878196,
    "toBlock": 12878196,
    "page": 1,
    "offset": 100,
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
