---
title: "Get Daily ENS Registration Count on Ethereum"
sidebarTitle: "dailyensregister"
description: "Returns the number of Ethereum Name Service (ENS) names registered each day over a date range. PRO endpoint — Ethereum only."
---

The Ethereum Name Service (ENS) allows users to register human-readable `.eth` names that resolve to wallet addresses and other on-chain data. Daily ENS registration counts serve as a proxy for user growth and web3 identity adoption. This endpoint is scoped to Ethereum mainnet only, since ENS is deployed exclusively on Ethereum.

<Note>
  This is a **PRO endpoint**, available to the [Standard Plan](/rate-limits) and above. This endpoint is available on **Ethereum mainnet only**.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  Set to `1` for Ethereum mainnet. This endpoint is Ethereum-only.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="dailyensregister">
  Set to `dailyensregister`.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format, e.g. `2026-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format, e.g. `2026-02-28`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order. Use `asc` for oldest-first or `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily ENS registration counts.

  <Expandable title="Result item fields">
    <ResponseField name="UTCDate" type="string">
      Date of the data point in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="unixTimeStamp" type="string">
      Start of the UTC date as a Unix timestamp in seconds.
    </ResponseField>
    <ResponseField name="ensRegistrationCount" type="number">
      Number of ENS names registered on this day.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=dailyensregister\
&startdate=2026-02-01\
&enddate=2026-02-28\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "dailyensregister",
  startdate: "2026-02-01",
  enddate: "2026-02-28",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "dailyensregister",
    "startdate": "2026-02-01",
    "enddate": "2026-02-28",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
