title: "Get ERC-721 NFT Collection Holdings for an Address"

description: "Retrieve all ERC-721 NFT collections and token counts owned by an address. Returns collection name, symbol, and quantity. Requires a Standard plan."
---

Use this endpoint to see which ERC-721 NFT collections a wallet or contract holds and how many tokens from each. Each result includes the collection's contract address, name, symbol, and the quantity owned. This is useful for building NFT portfolio views and wallet summaries.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="addresstokennftbalance">
  Set to `addresstokennftbalance` for this endpoint.
</ParamField>

<ParamField query="address" type="string" required>
  The wallet or contract address to check for NFT holdings. Example: `0x6b52e83941eb10f9c613c395a834457559a80114`.
</ParamField>

<ParamField query="page" type="integer">
  Page number for paginated results. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of records per page. Example: `100`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of ERC-721 collection holdings.
  <Expandable title="result item fields">
    <ResponseField name="TokenAddress" type="string">
      Contract address of the ERC-721 collection.
    </ResponseField>
    <ResponseField name="TokenName" type="string">
      Name of the NFT collection.
    </ResponseField>
    <ResponseField name="TokenSymbol" type="string">
      Symbol of the NFT collection.
    </ResponseField>
    <ResponseField name="TokenQuantity" type="string">
      Number of tokens from this collection held by the address.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=addresstokennftbalance\
&address=0x6b52e83941eb10f9c613c395a834457559a80114\
&page=1\
&offset=100\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "account",
  action: "addresstokennftbalance",
  address: "0x6b52e83941eb10f9c613c395a834457559a80114",
  page: "1",
  offset: "100",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "addresstokennftbalance",
    "address": "0x6b52e83941eb10f9c613c395a834457559a80114",
    "page": 1,
    "offset": 100,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
