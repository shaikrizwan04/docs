---
title: "Get Top Token Holders for an ERC-20 Contract"
sidebarTitle: "Top Holders"
description: "Retrieve the top holders of an ERC-20 token by contract address, ranked by balance. Returns up to 1000 holders. Requires a Standard plan API key."
---

Use this endpoint to find the largest holders of any ERC-20 token. Results include the holder's address, their balance, and whether the holder is a smart contract (`C`) or an externally owned account (`A`). This data is useful for concentration analysis, whale monitoring, and governance research.

<Note>
  This is a PRO endpoint, available on the [Standard Plan](/rate-limits) and above.
</Note>

<Warning>
  This endpoint is throttled to **2 calls/second** regardless of API Pro tier.
</Warning>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. For example, `1` for Ethereum mainnet or `42161` for Arbitrum. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="token">
  Set to `token` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="topholders">
  Set to `topholders` for this endpoint.
</ParamField>

<ParamField query="contractaddress" type="string" required>
  The ERC-20 token contract address. Example: `0x7fc66500c84a76ad7e9c93437bfc5ac33e2ddae9`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of top holders to return. Maximum is `1000`. Example: `100`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of top token holder records.
  <Expandable title="result item fields">
    <ResponseField name="TokenHolderAddress" type="string">
      Address of the token holder.
    </ResponseField>
    <ResponseField name="TokenHolderQuantity" type="string">
      Quantity of tokens held by this address.
    </ResponseField>
    <ResponseField name="TokenHolderAddressType" type="string">
      Type of holder address. `C` for a smart contract, `A` for an externally owned account (EOA).
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=token\
&action=topholders\
&contractaddress=0x7fc66500c84a76ad7e9c93437bfc5ac33e2ddae9\
&offset=10\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "token",
  action: "topholders",
  contractaddress: "0x7fc66500c84a76ad7e9c93437bfc5ac33e2ddae9",
  offset: "10",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "token",
    "action": "topholders",
    "contractaddress": "0x7fc66500c84a76ad7e9c93437bfc5ac33e2ddae9",
    "offset": 10,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
