The label master list is the canonical catalog of all label categories Etherscan uses to classify addresses — from exchanges and DeFi protocols to phishing and scam-flagged wallets. This endpoint returns a pre-signed download URL (valid for 5 minutes) for the full JSON export. Use the `labelslug` values from this list as inputs to the [Export Address Tags](/api-reference/endpoint/exportaddresstags-v2) endpoint to download all addresses associated with a specific label.

<Note>
  Metadata Exports are available exclusively to [Enterprise plan](https://etherscan.io/api/pricing) customers. [Contact Sales](https://etherscan.io/api/pricing#contactSection) to explore Enterprise access.
</Note>

<Tip>
  The `result` field is a temporary download URL, not the data itself. Fetch that URL within **5 minutes** to download the JSON label list. The URL includes AWS Signature credentials and expires quickly.
</Tip>

## Endpoint

This endpoint uses the metadata API base URL: `https://api-metadata.etherscan.io/v2/api`

## Parameters

<ParamField query="chainid" type="string" required>
  Chain ID for the label master list. Refer to supported mainnet chains on the [supported chains](/supported-chains) page.
</ParamField>

<ParamField query="module" type="string" required default="nametag">
  Set to `nametag`.
</ParamField>

<ParamField query="action" type="string" required default="getlabelmasterlist">
  Set to `getlabelmasterlist`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if a URL was generated, `0` on error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="string">
  Pre-signed temporary download URL for the label master list JSON file.
</ResponseField>

## Downloaded JSON Structure

Each entry in the downloaded JSON array contains:

<ResponseField name="labelname" type="string">Display name of the label, e.g. `Binance`.</ResponseField>
<ResponseField name="labelslug" type="string">Machine-readable slug for the label, e.g. `binance`. Use this as the `label` parameter in Export Address Tags.</ResponseField>
<ResponseField name="shortdescription" type="string">Description of the label category.</ResponseField>
<ResponseField name="notes" type="string">Additional notes about the label.</ResponseField>
<ResponseField name="lastupdatedtimestamp" type="number">Unix timestamp when the label was last updated.</ResponseField>

## Example

<CodeGroup>
```bash cURL
# Step 1: Get the download URL
curl "https://api-metadata.etherscan.io/v2/api\
?chainid=1\
&module=nametag\
&action=getlabelmasterlist\
&apikey=YOUR_API_KEY"

# Step 2: Download the JSON using the returned URL
# curl "<result_url_from_step_1>"
```

```javascript JavaScript
// Step 1: Get the download URL
const params = new URLSearchParams({
  chainid: "1",
  module: "nametag",
  action: "getlabelmasterlist",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api-metadata.etherscan.io/v2/api?${params}`);
const { result: downloadUrl } = await res.json();

// Step 2: Download the label list
const labelRes = await fetch(downloadUrl);
const labels = await labelRes.json();
console.log(`Total labels: ${labels.result.length}`);
```

```python Python
import requests

# Step 1: Get the download URL
params = {
    "chainid": "1",
    "module": "nametag",
    "action": "getlabelmasterlist",
    "apikey": "YOUR_API_KEY",
}
r = requests.get("https://api-metadata.etherscan.io/v2/api", params=params)
download_url = r.json()["result"]

# Step 2: Download the label list
labels = requests.get(download_url).json()
print(f"Total labels: {len(labels['result'])}")
```
