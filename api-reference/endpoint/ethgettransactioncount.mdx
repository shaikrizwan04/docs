---
title: "Get Transaction Count and Nonce for an Address (Proxy)"
sidebarTitle: "eth_getTransactionCount"
description: "Returns the number of transactions sent from an address (its nonce) at a specified block, mirroring the eth_getTransactionCount JSON-RPC method."
---

The transaction count for an address is also its nonce — the value you must include in every new transaction to prevent replay attacks and ensure ordering. This endpoint mirrors the standard `eth_getTransactionCount` JSON-RPC method. Use `latest` for the most recent nonce, or specify a block number to query the historical nonce at that point in time.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_getTransactionCount">
  Set to `eth_getTransactionCount`.
</ParamField>

<ParamField query="address" type="string" required>
  The address to query the nonce for, e.g. `0x4bd5900cb274ef15b153066d736bf3e83a9ba44e`.
</ParamField>

<ParamField query="tag" type="string" required>
  Block parameter: `latest`, `earliest`, `pending`, or a hex-encoded block number.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="string">
  The number of transactions sent from the address (nonce), as a `0x`-prefixed hex string.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_getTransactionCount\
&address=0x4bd5900cb274ef15b153066d736bf3e83a9ba44e\
&tag=latest\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_getTransactionCount",
  address: "0x4bd5900cb274ef15b153066d736bf3e83a9ba44e",
  tag: "latest",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
const nonce = parseInt(data.result, 16);
console.log(`Next nonce: ${nonce}`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_getTransactionCount",
    "address": "0x4bd5900cb274ef15b153066d736bf3e83a9ba44e",
    "tag": "latest",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
nonce = int(r.json()["result"], 16)
print(f"Next nonce: {nonce}")
```
</CodeGroup>
