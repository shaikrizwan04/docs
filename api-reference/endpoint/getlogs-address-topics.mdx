---
title: "Get Event Logs by Contract Address and Topic Filters"
sidebarTitle: "getLogs (Combined)"
description: "Retrieve event logs from a contract address filtered by EVM topic values and block range, combining both address and topic constraints in one query."
---

This endpoint combines address-based and topic-based filtering so you can narrow results to a specific contract's logs that also match particular event types or indexed parameters. It is the most precise variant of the `getLogs` family — use it when you know both the emitting contract and the events you want to observe, such as tracking NFT sales at a marketplace contract by filtering for the sale event signature alongside a specific seller address.

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="logs">
  Set to `logs`.
</ParamField>

<ParamField query="action" type="string" required default="getLogs">
  Set to `getLogs`.
</ParamField>

<ParamField query="address" type="string" required>
  The contract address to retrieve logs from.
</ParamField>

<ParamField query="fromBlock" type="integer" required>
  The starting block number (inclusive) for the query range.
</ParamField>

<ParamField query="toBlock" type="integer" required>
  The ending block number (inclusive) for the query range.
</ParamField>

<ParamField query="topic0" type="string">
  First topic filter. Typically the keccak256 hash of the event signature.
</ParamField>

<ParamField query="topic1" type="string">
  Second topic filter.
</ParamField>

<ParamField query="topic2" type="string">
  Third topic filter.
</ParamField>

<ParamField query="topic3" type="string">
  Fourth topic filter.
</ParamField>

<ParamField query="topic0_1_opr" type="string">
  Logical operator between `topic0` and `topic1`. Either `and` or `or`.
</ParamField>

<ParamField query="topic0_2_opr" type="string">
  Logical operator between `topic0` and `topic2`. Either `and` or `or`.
</ParamField>

<ParamField query="topic0_3_opr" type="string">
  Logical operator between `topic0` and `topic3`. Either `and` or `or`.
</ParamField>

<ParamField query="topic1_2_opr" type="string">
  Logical operator between `topic1` and `topic2`. Either `and` or `or`.
</ParamField>

<ParamField query="topic1_3_opr" type="string">
  Logical operator between `topic1` and `topic3`. Either `and` or `or`.
</ParamField>

<ParamField query="topic2_3_opr" type="string">
  Logical operator between `topic2` and `topic3`. Either `and` or `or`.
</ParamField>

<ParamField query="page" type="integer">
  Page number for pagination. Starts at `1`.
</ParamField>

<ParamField query="offset" type="integer">
  Number of records per page. Maximum is `1000`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` if it returned no records or encountered an error.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of event log objects.

  <Expandable title="Log object fields">
    <ResponseField name="address" type="string">
      Address of the contract that emitted the log.
    </ResponseField>
    <ResponseField name="topics" type="array">
      Array of indexed log topics.
    </ResponseField>
    <ResponseField name="data" type="string">
      Non-indexed event data, hex-encoded.
    </ResponseField>
    <ResponseField name="blockNumber" type="string">
      Block number where the log was recorded, as a hex string.
    </ResponseField>
    <ResponseField name="blockHash" type="string">
      Hash of the block containing the log.
    </ResponseField>
    <ResponseField name="timeStamp" type="string">
      Unix timestamp of the block, as a hex string.
    </ResponseField>
    <ResponseField name="gasPrice" type="string">
      Gas price of the transaction, in wei (hex).
    </ResponseField>
    <ResponseField name="gasUsed" type="string">
      Gas consumed by the transaction, as a hex string.
    </ResponseField>
    <ResponseField name="logIndex" type="string">
      Index of this log within the block, as a hex string.
    </ResponseField>
    <ResponseField name="transactionHash" type="string">
      Hash of the transaction that produced the log.
    </ResponseField>
    <ResponseField name="transactionIndex" type="string">
      Index of the transaction within the block, as a hex string.
    </ResponseField>
  </Expandable>
</ResponseField>
