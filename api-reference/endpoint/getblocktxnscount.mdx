---
title: "Get Block Transaction Counts by Block Number"
sidebarTitle: "Block Tx Count"
description: "Retrieve a full breakdown of transaction counts — including ERC-20, ERC-721, and ERC-1155 transfers — for any block number."
---

Use this endpoint to get a complete count of all transaction types in a specific block. The response breaks down regular transactions, internal transactions, and token transfer events by standard, giving you a quick overview of block activity.

<Note>
  This endpoint is currently available for Ethereum mainnet only.
</Note>

## Query Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet. See the full list of [supported chains](/supported-chains).
</ParamField>

<ParamField query="module" type="string" required default="block">
  Set to `block` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="getblocktxnscount">
  Set to `getblocktxnscount` for this endpoint.
</ParamField>

<ParamField query="blockno" type="integer" required>
  The block number to retrieve transaction counts for. Example: `24884529`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response Fields

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="object">
  <Expandable title="result fields">
    <ResponseField name="block" type="number">
      The queried block number.
    </ResponseField>
    <ResponseField name="txsCount" type="number">
      Total number of top-level transactions in the block.
    </ResponseField>
    <ResponseField name="internalTxsCount" type="number">
      Number of internal (contract-to-contract) transactions.
    </ResponseField>
    <ResponseField name="erc20TxsCount" type="number">
      Number of ERC-20 token transfer events emitted in the block.
    </ResponseField>
    <ResponseField name="erc721TxsCount" type="number">
      Number of ERC-721 (NFT) token transfer events emitted in the block.
    </ResponseField>
    <ResponseField name="erc1155TxsCount" type="number">
      Number of ERC-1155 multi-token transfer events emitted in the block.
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=block\
&action=getblocktxnscount\
&blockno=24884529\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "block",
  action: "getblocktxnscount",
  blockno: "24884529",
  apikey: "YOUR_API_KEY",
});

const response = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await response.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "block",
    "action": "getblocktxnscount",
    "blockno": 24884529,
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json()["result"])
```
