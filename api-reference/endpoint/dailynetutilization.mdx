---
title: "Get Daily Average Network Block Gas Utilization Ratio"
sidebarTitle: "dailynetutilization"
description: "Returns the daily average gas utilization ratio (gasUsed/gasLimit) across all blocks, as a decimal between 0 and 1. PRO endpoint — Standard plan and above."
---

Network utilization measures how full blocks are on average — a ratio of `gasUsed / gasLimit` per block, averaged over each day. A value near `1.0` means blocks are consistently full, a sign that demand exceeds capacity and users are competing aggressively for block space. Values well below `1.0` indicate spare capacity. Use this metric alongside gas price data to understand fee market dynamics over time.

<Note>
  This is a **PRO endpoint**, available to the [Standard Plan](/rate-limits) and above. Upgrade your API key to access it.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="stats">
  Set to `stats`.
</ParamField>

<ParamField query="action" type="string" required default="dailynetutilization">
  Set to `dailynetutilization`.
</ParamField>

<ParamField query="startdate" type="string" required>
  Start of the date range in `yyyy-MM-dd` format, e.g. `2019-02-01`.
</ParamField>

<ParamField query="enddate" type="string" required>
  End of the date range in `yyyy-MM-dd` format, e.g. `2019-02-28`.
</ParamField>

<ParamField query="sort" type="string">
  Sort order. Use `asc` for oldest-first or `desc` for newest-first.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` on error or no records.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success, or an error description such as `NOTOK`.
</ResponseField>

<ResponseField name="result" type="array">
  Array of daily network utilization data points.

  <Expandable title="Result item fields">
    <ResponseField name="UTCDate" type="string">
      Date of the data point in `YYYY-MM-DD` format (UTC).
    </ResponseField>
    <ResponseField name="unixTimeStamp" type="string">
      Start of the UTC date as a Unix timestamp in seconds.
    </ResponseField>
    <ResponseField name="networkUtilization" type="string">
      Average network utilization on this day as a ratio between `0` (empty) and `1` (completely full).
    </ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=stats\
&action=dailynetutilization\
&startdate=2019-02-01\
&enddate=2019-02-28\
&sort=asc\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "stats",
  action: "dailynetutilization",
  startdate: "2019-02-01",
  enddate: "2019-02-28",
  sort: "asc",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const data = await res.json();
console.log(data.result);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "stats",
    "action": "dailynetutilization",
    "startdate": "2019-02-01",
    "enddate": "2019-02-28",
    "sort": "asc",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
print(r.json()["result"])
```
