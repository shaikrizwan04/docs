---
title: "Get Current Gas Price in Wei"
sidebarTitle: "eth_gasPrice"
description: "Returns the current gas price in wei as reported by the node, mirroring the standard JSON-RPC eth_gasPrice method."
---

This endpoint mirrors the standard `eth_gasPrice` JSON-RPC method, returning the current gas price in wei as a hex-encoded string. This is the median gas price reported by the connected node based on recent blocks. For EIP-1559 transactions you'll want to use the [Gas Oracle](/api-reference/endpoint/gasoracle) instead, which provides base fee and priority fee recommendations. Use `eth_gasPrice` when you need a simple wei-denominated price for legacy transaction types.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_gasPrice">
  Set to `eth_gasPrice`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="string">
  Current gas price in wei, as a `0x`-prefixed hex string. Divide by 10^9 to convert to Gwei.
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_gasPrice\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_gasPrice",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const { result } = await res.json();
const gasPriceGwei = Number(BigInt(result)) / 1e9;
console.log(`Gas price: ${gasPriceGwei} Gwei`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_gasPrice",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
gas_wei = int(r.json()["result"], 16)
print(f"Gas price: {gas_wei / 1e9} Gwei")
```
</CodeGroup>
