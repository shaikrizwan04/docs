---
title: "Get Transaction Details by Hash"
sidebarTitle: "eth_getTransactionByHash"
description: "Returns the full transaction object for a given transaction hash, including sender, recipient, value, gas, and input data."
---

This endpoint mirrors the standard `eth_getTransactionByHash` JSON-RPC method. Pass a transaction hash to retrieve all fields of the transaction as it was submitted to the network — including the sender address, recipient, ETH value, gas parameters, and raw input data. Note that this returns the transaction as broadcast, not the execution result; use `eth_getTransactionReceipt` for execution outcomes.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_getTransactionByHash">
  Set to `eth_getTransactionByHash`.
</ParamField>

<ParamField query="txhash" type="string" required>
  The transaction hash to look up, e.g. `0x1e2910a262b1008d0616a0beb24c1a491d78771baa54a33e66065e03b1f46bc1`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="object">
  Transaction object, or `null` if not found.

  <Expandable title="Transaction object fields">
    <ResponseField name="hash" type="string">Transaction hash.</ResponseField>
    <ResponseField name="nonce" type="string">Sender's transaction count at the time of submission, hex-encoded.</ResponseField>
    <ResponseField name="blockHash" type="string">Hash of the block that includes this transaction, or `null` if pending.</ResponseField>
    <ResponseField name="blockNumber" type="string">Block number, hex-encoded, or `null` if pending.</ResponseField>
    <ResponseField name="transactionIndex" type="string">Index of the transaction within its block, hex-encoded.</ResponseField>
    <ResponseField name="from" type="string">Address that signed and sent the transaction.</ResponseField>
    <ResponseField name="to" type="string">Recipient address, or `null` for contract creation.</ResponseField>
    <ResponseField name="value" type="string">ETH transferred in wei, hex-encoded.</ResponseField>
    <ResponseField name="gasPrice" type="string">Gas price in wei, hex-encoded.</ResponseField>
    <ResponseField name="gas" type="string">Gas limit provided by the sender, hex-encoded.</ResponseField>
    <ResponseField name="input" type="string">Hex-encoded input data (calldata or constructor bytecode).</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_getTransactionByHash\
&txhash=0x1e2910a262b1008d0616a0beb24c1a491d78771baa54a33e66065e03b1f46bc1\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_getTransactionByHash",
  txhash: "0x1e2910a262b1008d0616a0beb24c1a491d78771baa54a33e66065e03b1f46bc1",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const { result } = await res.json();
console.log(`From: ${result.from} → To: ${result.to}`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_getTransactionByHash",
    "txhash": "0x1e2910a262b1008d0616a0beb24c1a491d78771baa54a33e66065e03b1f46bc1",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
tx = r.json()["result"]
print(f"From: {tx['from']}, Value: {int(tx['value'], 16) / 1e18} ETH")
```
