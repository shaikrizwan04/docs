---
title: "Get Full Block Data by Block Number (eth_getBlockByNumber)"
sidebarTitle: "eth_getBlockByNumber"
description: "Returns complete block metadata for a given block number, including timestamp, gas, and optionally full transaction objects, via eth_getBlockByNumber."
---

This endpoint mirrors the standard Ethereum JSON-RPC `eth_getBlockByNumber` method, returning complete block metadata for any block you specify. Set the `boolean` parameter to `true` to include full transaction objects in the response, or `false` to include only transaction hashes. Use this endpoint to inspect block headers, retrieve miner/validator information, or enumerate every transaction in a block.

<Note>
  This is a **Geth/Parity Proxy** endpoint that wraps the standard JSON-RPC interface. The `tag` parameter accepts a hex-encoded block number (`0x...`) or the string `latest`.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain to query. Use `1` for Ethereum mainnet. See [supported chains](/supported-chains) for a full list.
</ParamField>

<ParamField query="module" type="string" required default="proxy">
  Set to `proxy`.
</ParamField>

<ParamField query="action" type="string" required default="eth_getBlockByNumber">
  Set to `eth_getBlockByNumber`.
</ParamField>

<ParamField query="tag" type="string" required>
  Hex-encoded block number (e.g. `0x10d4f`) or `latest` for the most recent block.
</ParamField>

<ParamField query="boolean" type="boolean" required>
  Set to `true` to include full transaction objects, or `false` for transaction hashes only.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Get one here](/set-up-your-api-key).
</ParamField>

## Response

<ResponseField name="jsonrpc" type="string">
  JSON-RPC version. Always `"2.0"`.
</ResponseField>

<ResponseField name="id" type="integer">
  Request ID echoed back.
</ResponseField>

<ResponseField name="result" type="object">
  Block data object, or `null` if the block was not found.

  <Expandable title="Block object fields">
    <ResponseField name="number" type="string">Block number, hex-encoded.</ResponseField>
    <ResponseField name="hash" type="string">Block hash.</ResponseField>
    <ResponseField name="parentHash" type="string">Hash of the parent block.</ResponseField>
    <ResponseField name="nonce" type="string">Proof-of-Work nonce (all zeros post-Merge).</ResponseField>
    <ResponseField name="sha3Uncles" type="string">SHA3 hash of the uncles list.</ResponseField>
    <ResponseField name="logsBloom" type="string">Bloom filter of the block's logs.</ResponseField>
    <ResponseField name="transactionsRoot" type="string">Root of the transaction trie.</ResponseField>
    <ResponseField name="stateRoot" type="string">Root of the state trie.</ResponseField>
    <ResponseField name="receiptsRoot" type="string">Root of the receipts trie.</ResponseField>
    <ResponseField name="miner" type="string">Address that received the block reward.</ResponseField>
    <ResponseField name="difficulty" type="string">Block difficulty, hex-encoded.</ResponseField>
    <ResponseField name="totalDifficulty" type="string">Total chain difficulty up to this block.</ResponseField>
    <ResponseField name="extraData" type="string">Extra data field included by the miner/validator.</ResponseField>
    <ResponseField name="size" type="string">Size of the block in bytes, hex-encoded.</ResponseField>
    <ResponseField name="gasLimit" type="string">Maximum gas allowed in the block, hex-encoded.</ResponseField>
    <ResponseField name="gasUsed" type="string">Total gas used by all transactions, hex-encoded.</ResponseField>
    <ResponseField name="timestamp" type="string">Unix timestamp when the block was collated, hex-encoded.</ResponseField>
    <ResponseField name="transactions" type="array">Transaction hashes or full transaction objects, depending on `boolean`.</ResponseField>
    <ResponseField name="uncles" type="array">Array of uncle block hashes.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=proxy\
&action=eth_getBlockByNumber\
&tag=0x10d4f\
&boolean=true\
&apikey=YOUR_API_KEY"
```

```javascript JavaScript
const params = new URLSearchParams({
  chainid: "1",
  module: "proxy",
  action: "eth_getBlockByNumber",
  tag: "0x10d4f",
  boolean: "true",
  apikey: "YOUR_API_KEY",
});

const res = await fetch(`https://api.etherscan.io/v2/api?${params}`);
const { result } = await res.json();
console.log(`Block #${parseInt(result.number, 16)} has ${result.transactions.length} transactions`);
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "proxy",
    "action": "eth_getBlockByNumber",
    "tag": "0x10d4f",
    "boolean": "true",
    "apikey": "YOUR_API_KEY",
}

r = requests.get("https://api.etherscan.io/v2/api", params=params)
block = r.json()["result"]
print(f"Block {int(block['number'], 16)}: {len(block['transactions'])} txs")
```
