---
title: "Get All Internal Transactions Within a Transaction Hash"
sidebarTitle: "txlistinternal (Hash)"
description: "Retrieve all internal transactions executed within a specific transaction hash. Only returns internal calls with non-zero ETH value transfers."
---

Use this endpoint to inspect all internal calls that were executed as part of a single transaction. Given a parent transaction hash, the API returns every internal call that occurred during that transaction's execution — including calls between contracts, contract creations, and value transfers. This is useful for debugging complex DeFi transactions, understanding how ETH flowed through a multi-step interaction, or auditing a specific transaction's behavior.

<Note>
  Only internal transactions with a **non-zero value** transfer are returned by this endpoint. Zero-value internal calls (e.g., pure function calls between contracts) are not included.
</Note>

## Parameters

<ParamField query="chainid" type="string" required>
  The chain ID to query. Use `1` for Ethereum mainnet or any chain from the [supported chains](/supported-chains) list.
</ParamField>

<ParamField query="module" type="string" required default="account">
  Set to `account` for this endpoint.
</ParamField>

<ParamField query="action" type="string" required default="txlistinternal">
  Set to `txlistinternal` for this endpoint.
</ParamField>

<ParamField query="txhash" type="string" required>
  The transaction hash to inspect for internal calls, for example `0x40eb908387324f2b575b4879cd9d7188f69c8fc9d87c901b9e2daaea4b442170`.
</ParamField>

<ParamField query="apikey" type="string" required>
  Your Etherscan API key. [Set one up](/set-up-your-api-key) if you don't have one.
</ParamField>

## Response

<ResponseField name="status" type="string">
  `1` if the request returned data, `0` otherwise.
</ResponseField>

<ResponseField name="message" type="string">
  `OK` on success. See [common error messages](/common-error-messages) for error values.
</ResponseField>

<ResponseField name="result" type="array">
  An array of internal transaction objects within the specified transaction.

  <Expandable title="result[]">
    <ResponseField name="blockNumber" type="string">Block number in which the parent transaction was included.</ResponseField>
    <ResponseField name="timeStamp" type="string">Time the block was mined, as a UNIX timestamp in seconds.</ResponseField>
    <ResponseField name="from" type="string">Address that initiated the internal call.</ResponseField>
    <ResponseField name="to" type="string">Recipient address. Empty for contract-creation calls.</ResponseField>
    <ResponseField name="value" type="string">Amount of the native token transferred, in wei.</ResponseField>
    <ResponseField name="contractAddress" type="string">Address of any contract created by this internal call. Empty otherwise.</ResponseField>
    <ResponseField name="input" type="string">Input data of the internal call, as a hex string.</ResponseField>
    <ResponseField name="type" type="string">Type of internal call: `call`, `create`, `create2`, or `selfdestruct`.</ResponseField>
    <ResponseField name="gas" type="string">Gas forwarded to this internal call.</ResponseField>
    <ResponseField name="gasUsed" type="string">Gas actually consumed by this internal call.</ResponseField>
    <ResponseField name="isError" type="string">`0` if the call succeeded, `1` if it failed.</ResponseField>
    <ResponseField name="errCode" type="string">Error code if the call failed. Empty on success.</ResponseField>
  </Expandable>
</ResponseField>

## Example

<CodeGroup>
```bash cURL
curl "https://api.etherscan.io/v2/api\
?chainid=1\
&module=account\
&action=txlistinternal\
&txhash=0x40eb908387324f2b575b4879cd9d7188f69c8fc9d87c901b9e2daaea4b442170\
&apikey=YOUR_API_KEY"
```

```python Python
import requests

params = {
    "chainid": "1",
    "module": "account",
    "action": "txlistinternal",
    "txhash": "0x40eb908387324f2b575b4879cd9d7188f69c8fc9d87c901b9e2daaea4b442170",
    "apikey": "YOUR_API_KEY",
}

response = requests.get("https://api.etherscan.io/v2/api", params=params)
print(response.json())
```
