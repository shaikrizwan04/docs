## Single API to access our Endpoints & Metadata

Everything you need for powerful utility when you're building.

[/account/\*\\ \\ **Account Endpoints**\\ \\ Get balances, transactions, token transfers, mined blocks, withdrawals, and funded-by data for an address.](https://docs.etherscan.io/api-reference/endpoint/balance)

[/block/\*\\ \\ **Block Endpoints**\\ \\ Get block rewards, transaction counts, countdowns, block numbers by timestamp, and daily block statistics.](https://docs.etherscan.io/api-reference/endpoint/getblockreward)

[/contract/\*\\ \\ **Contract Endpoints**\\ \\ Fetch contract source code, ABIs, creators, creation transactions, and verification status.](https://docs.etherscan.io/api-reference/endpoint/getsourcecode)

[/gastracker/\*\\ \\ **Gas Tracker Endpoints**\\ \\ Read gas oracle recommendations, estimate confirmation time, and review daily gas statistics.](https://docs.etherscan.io/api-reference/endpoint/gasoracle)

[/proxy/\*\\ \\ **Geth/Parity Proxy**\\ \\ Use JSON-RPC compatible methods for blocks, calls, storage, gas price, transactions, receipts, and raw sends.](https://docs.etherscan.io/api-reference/endpoint/ethblocknumber)

[/logs/\*\\ \\ **Logs Endpoints**\\ \\ Retrieve event logs by address, topics, or both with optional block range filtering.](https://docs.etherscan.io/api-reference/endpoint/getlogs)

[/stats/\*\\ \\ **Stats Endpoints**\\ \\ Get native token price and supply, node count, chain size, and daily network statistics.](https://docs.etherscan.io/api-reference/endpoint/ethsupply)

[/transaction/\*\\ \\ **Transaction Endpoints**\\ \\ Check contract execution status and transaction receipt status by transaction hash.](https://docs.etherscan.io/api-reference/endpoint/getstatus)

[/token/\*\\ \\ **Token Endpoints**\\ \\ Fetch token supply, balances, holder lists, holder counts, top holders, token info, and token inventory.](https://docs.etherscan.io/api-reference/endpoint/tokeninfo)

[/account/\*\\ \\ **L2 Deposits/Withdrawals**\\ \\ Retrieve Plasma deposits, bridge deposits, and withdrawal transactions for an address.](https://docs.etherscan.io/api-reference/endpoint/getdeposittxs)

[/nametag/\*\\ \\ **Name Tags**\\ \\ Get name tags, labels, reputation, and related metadata for the specified address.](https://docs.etherscan.io/api-reference/endpoint/getaddresstag)

[/getapilimit\\ \\ **Usage**\\ \\ Check API credit usage and limits, and retrieve supported chain metadata with Chainlist.](https://docs.etherscan.io/api-reference/endpoint/getapilimit)

[**All API Endpoints**\\ \\ View all our available endpoints on Etherscan API documentation.\\ \\ View All Endpoints](https://docs.etherscan.io/)
