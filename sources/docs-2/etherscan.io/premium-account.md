## Etherscan Premium FAQ

## What is Etherscan Premium?

Etherscan Premium is an optional subscription that gives frequent users access to features that go beyond what we can sustainably offer for free, including higher limits, exclusive tools, and an ad-free experience.

## Does Etherscan Premium include API access?

No. Premium and the [Etherscan API](https://etherscan.io/api/pricing) are two separate products. Subscribing to Premium does not include paid API access. Premium covers your experience on the Etherscan website. The API is a separate subscription for programmatic access to blockchain data, with its own rate limits and pricing. If you need paid API access, choose a plan on the [API page](https://etherscan.io/api/pricing).

## Is Etherscan still free?

Yes. Everything you use today stays free. Premium makes it possible to offer resource-intensive features to users who want them, while keeping the core explorer free and accessible for everyone. Free users will continue to receive new features over time too.

## How can I cancel my subscription?

Please [contact us](mailto:premiumacc_billing@etherscan.io) should you wish to cancel your subscription. We will assist you accordingly. You retain Premium benefits until the end of your current billing period, after which your account returns to free.
