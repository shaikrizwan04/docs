## Broadcast Raw Transaction

[API](https://docs.etherscan.io/api-reference/endpoint/ethsendrawtransaction)

This page allows you to paste a Signed Raw Transaction in hex format (i.e. characters 0-9, a-f) and broadcast it over the Ethereum network.

Enter signed transaction hex

Tip: You can also broadcast programatically via our [\[eth\_sendRawTransaction\]](https://docs.etherscan.io/api-reference/endpoint/ethsendrawtransaction). Accepts the paramater "hex" for prefilling the input box above (i.e [Click here](https://etherscan.io/pushTx?hex=0x000000))
