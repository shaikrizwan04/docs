The Etherscan AI tools give your agents and coding assistants the same live onchain data that powers etherscan.io — across all 60+ supported chains. Whether you are building a conversational agent, a terminal automation workflow, or a specialized onchain investigation pipeline, there is an interface designed for the job. Each tool is built around the Etherscan API, so every answer is grounded in real chain data. Start by [creating a free API key](/set-up-your-api-key), then pick the tool that fits your workflow below.

<Note>
  Chain availability and endpoint access depend on your [API plan](https://etherscan.io/api/pricing). All tools support the full list of [supported chains](/supported-chains).
</Note>

## How the tools fit together

Each tool targets a different point in an AI workflow. Use them individually or combine them:

- **MCP** is the right choice when you want a conversational agent to answer onchain questions interactively. Connect it once and the agent selects the right API tools on your behalf.
- **CLI** is the right choice for terminal automation, CI pipelines, and scripting. Output is structured JSON by default so it feeds cleanly into `jq`, Python, or any downstream processor.
- **Skills** are prompt-level instructions you install into an agent once. They teach the agent a specific onchain workflow — routing tasks (Orchestrator), tracing fund flows (Flow), reviewing contract source (Contract Review), or debugging transactions (Transaction Debugger) — so you can ask in plain language without specifying API details.
