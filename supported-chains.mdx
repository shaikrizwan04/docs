The Etherscan API gives you access to onchain data across 60+ EVM-compatible chains through a single endpoint and a single API key. To switch chains, change the `chainid` query parameter in your request — everything else stays the same. Mainnets and their corresponding testnets are both supported, so you can develop and test against the same API before deploying to production.

## Switching chains

Every API call goes to `https://api.etherscan.io/v2/api`. The `chainid` parameter tells the API which network to query:

```bash
# Ethereum mainnet
curl 'https://api.etherscan.io/v2/api?chainid=1&module=account&action=balance&address=0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045&tag=latest&apikey=YOUR_API_KEY'

# Base mainnet — only chainid changes
curl 'https://api.etherscan.io/v2/api?chainid=8453&module=account&action=balance&address=0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045&tag=latest&apikey=YOUR_API_KEY'

# Arbitrum One — only chainid changes
curl 'https://api.etherscan.io/v2/api?chainid=42161&module=account&action=balance&address=0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045&tag=latest&apikey=YOUR_API_KEY'
```

<Tip>
  Source code and ABI endpoints are available on all chains for every API plan, including the Free tier.
</Tip>

## Plan availability

Some chains require a paid plan. Chains marked **Free Tier Available** are accessible on every plan, including the free tier. Chains marked **Paid Tier Only** require a Lite plan or higher.

<Note>
  Gnosis (Chain ID 100) community endpoints will require a **Lite plan or above** starting **September 1, 2026**. Pro endpoints on Gnosis require a **Standard plan or above**. Source code and ABI endpoints remain available on the Free tier.
</Note>

## Retrieve the chain list programmatically

Use the `chainlist` endpoint to fetch the complete, up-to-date list of all supported chains — including their chain IDs, names, and explorer URLs — directly from the API:

```bash
curl 'https://api.etherscan.io/v2/api?module=chainlist&action=chainlist&apikey=YOUR_API_KEY'
```

A successful response returns an array of chain objects:

```json
{
  "status": "1",
  "message": "OK",
  "result": [
    {
      "chainname": "Ethereum Mainnet",
      "chainid": "1",
      "blockexplorer": "https://etherscan.io",
      "apiurl": "https://api.etherscan.io/v2/api"
    },
    {
      "chainname": "BNB Smart Chain Mainnet",
      "chainid": "56",
      "blockexplorer": "https://bscscan.com",
      "apiurl": "https://api.etherscan.io/v2/api"
    }
  ]
}
```

<Tip>
  Call the `chainlist` endpoint at application startup to keep your supported-chain list in sync automatically, rather than hardcoding chain IDs.
</Tip>
