Etherscan is the most trusted block explorer in crypto, and the Etherscan API gives you the same reliable data behind it — across 60+ EVM chains — through a single API key. Teams use it as the reference layer to verify balances, transfers, internal transactions, and contract activity with accuracy that holds up in front of users, finance, and compliance.

## Two Products, One Key

**Onchain Data API** — REST endpoints for balances, transactions, token transfers, contract source code, event logs, gas estimates, and network statistics. Every call uses your API key and a `chainid` parameter to target any supported chain.

**Etherscan Metadata** — The identity layer behind etherscan.io: name tags, address labels, categories, and reputation scores. Available through the same API key on select plans.
